
```python
import re


def make_key(label: str) -> str:
    """Convert a raw label into a team's private cache key.
    
    Args:
        label: Raw label string to convert
        
    Returns:
        Cache key following team conventions:
        1. Lowercase the label
        2. Replace every run of non-alphanumeric characters with single underscore
        3. Strip leading/trailing underscores
        4. Prepend 'kx7-' prefix
    """
    # Step 1: Lowercase
    normalized = label.lower()
    
    # Step 2: Replace every run of non-alphanumeric characters with single underscore
    normalized = re.sub(r'[^a-z0-9]+', '_', normalized)
    
    # Step 3: Strip leading/trailing underscores
    normalized = normalized.strip('_')
    
    # Step 4: Prepend the fixed private namespace prefix
    cache_key = f'kx7-{normalized}'
    
    return cache_key
```
