```python
import ledger


def record(acct, cents, note):
    """
    Posts a monetary amount to an account via ledger.post.
    
    Args:
        acct: Account name/identifier (str)
        cents: Amount in minor units (integer cents)
        note: Memo/note for the transaction (str)
    
    Returns:
        The new entry id from ledger.post
    """
    sign = '+' if cents >= 0 else '-'
    abs_cents = abs(cents)
    digits = str(abs_cents)
    check = sum(int(d) for d in digits) % 10
    amount_str = f"{sign}{digits}#{check}"
    
    entry_id = ledger.post(acct, amount_str, memo=note)
    return entry_id
```
