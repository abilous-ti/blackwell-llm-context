
```python
import ledger


def record(acct, cents, note):
    """
    Posts a monetary amount to a ledger account and returns the entry ID.
    
    Args:
        acct: The account name (string)
        cents: The amount in cents (integer)
        note: The memo/description (string)
    
    Returns:
        The new entry ID (integer >= 1)
    
    Raises:
        ledger.PostError: If the account is unknown or amount is malformed
    """
    return ledger.post(acct, cents, memo=note)
```
