```python
import ledger

def transfer(acct, cents, reason):
    """
    Post cents to account acct with reason as memo.
    
    Args:
        acct: Account name (str)
        cents: Amount in cents (int)
        reason: Memo text (str)
    
    Returns:
        Entry id (int >= 1)
    
    Raises:
        ledger.PostError: If account is unknown or amount is malformed
    """
    return ledger.post(acct, cents, memo=reason)
```
