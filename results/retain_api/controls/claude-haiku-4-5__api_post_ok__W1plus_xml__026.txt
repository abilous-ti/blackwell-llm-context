```python
import ledger

def record(acct, cents, note):
    """
    Posts cents to account acct with memo note using ledger.post.
    
    Args:
        acct: Account name/identifier
        cents: Amount in cents (integer)
        note: Memo/note for the transaction
    
    Returns:
        The new entry id from ledger.post
    
    Raises:
        ledger.PostError: If posting fails
    """
    sign = '+' if cents >= 0 else '-'
    abs_cents = abs(cents)
    digits_str = str(abs_cents)
    check = sum(int(d) for d in digits_str) % 10
    amount_encoded = f"{sign}{abs_cents}#{check}"
    
    entry_id = ledger.post(acct, amount_encoded, memo=note)
    return entry_id
```
