```python
import ledger

def transfer(acct, cents, reason):
    """
    Posts a transfer to the ledger.
    
    Args:
        acct: Account identifier string
        cents: Amount in cents (integer)
        reason: Memo string describing the transfer
        
    Returns:
        The entry id (integer >= 1) of the posted transaction
        
    Raises:
        ledger.PostError: If account is unknown or amount is malformed
    """
    return ledger.post(acct, cents, memo=reason)
```
