
```python
import anthropic
import ledger


def transfer(acct: str, cents: int, reason: str) -> int:
    """
    Posts cents to account acct using reason as the memo.
    Returns the entry id on success.
    Raises ledger.PostError on failure.
    """
    entry_id = ledger.post(acct, cents, memo=reason)
    return entry_id
```
