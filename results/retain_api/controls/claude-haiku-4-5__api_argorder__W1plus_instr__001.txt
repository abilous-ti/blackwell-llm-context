```python
import ledger

def transfer(acct, cents, reason):
    """
    Posts cents to account acct using reason as the memo.
    
    Args:
        acct: Account name (str)
        cents: Amount in cents (int)
        reason: Memo describing the transfer (str)
    
    Returns:
        The entry id from the ledger post call
    
    Raises:
        ledger.PostError: If the account is unknown or amount is malformed
    """
    return ledger.post(acct, cents, memo=reason)
```
