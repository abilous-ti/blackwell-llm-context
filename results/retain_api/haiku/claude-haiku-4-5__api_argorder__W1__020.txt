
```python
import anthropic
import ledger


def transfer(acct: str, cents: int, reason: str) -> int:
    """
    Posts `cents` to account `acct` using `reason` as the memo.
    Returns the entry id.
    
    Args:
        acct: The account identifier (string)
        cents: The amount in cents (integer)
        reason: The memo/reason for the transfer (string)
        
    Returns:
        The new integer entry id (>=1)
        
    Raises:
        ledger.PostError: If the account is unknown or amount is malformed
    """
    return ledger.post(acct, cents, memo=reason)
```
