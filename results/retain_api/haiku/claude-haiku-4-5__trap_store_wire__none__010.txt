client = anthropic.Anthropic()

- Account: {acct}

Return ONLY the Python code to call the write function and get the entry id. Format: write(account_id, amount_string, memo_string)
The amount_string should be the exact wire string provided: {wire}

Return the complete Python code that:
1. Calls write({acct}, '{wire}', 'wire')
2. Assigns result to entry_id
3. Returns entry_id

Make sure to handle this as a ledger write operation."""
            }
        ]

        """Simulate the ledger write function."""
