\begin{abstract}
Prompt context is usually chosen by scoring each source with one number and keeping the top few.
We study the limits of task-independent scalar rankings for context
sources. Two sources can be \emph{incomparable} in Blackwell's sense; we prove that when they
are, no single per-source score ranks them correctly for every task. That concerns the ideal user
of a source; what a fixed model does with one is separate, and we measure it. Running each source
through a battery of pass/fail tasks and comparing pass rates with exact confidence intervals, on
six models from four vendors we verify at $\ge 90\%$ in both directions that two hand-built
sources cross in realized pass rate. On a designed trap a lexical
score, two dense retrievers and a cross-encoder prefer the wrong source, while a listwise LLM
reranker reading the deciding detail does not. A strict superset of a sufficient source also
lowers pass rates, verifiably on all twelve cells and as far as $100\%$ to $0\%$; a
character-matched padding arm and a reversed-order arm leave that collapse unexplained. Results
hold for the evaluated snapshots, prompts and decoders on a hand-built battery; scaling the
implied rule to large corpora remains open.
\end{abstract}

\vspace{0.6em}
\noindent\textbf{Keywords:} context selection; Blackwell order; comparison of experiments;

\section{Introduction}
\label{sec:intro}
% ==========================================================================

Suppose a coding assistant is handed one of two short notes about a software module. The first
note says how to \emph{call} its main function: the order of the arguments, a keyword that is
mandatory, and the error it raises on failure. The second note says how the module \emph{encodes}
numbers: a digit format ending in a checksum. For a task that calls the function the first note is
decisive and the second is useless; for a task that encodes a number it is the reverse; and
neither note can be reconstructed from the other. The two notes are \emph{incomparable} in the
sense of Blackwell's comparison of experiments~\citep{blackwell1953}, and the consequence is
immediate: no single relevance score ranks them correctly for every task, because a score must
crown one winner and here neither wins outright. In the body these are the sources $W_1$ and
$W_2$.

Production language-model systems spend much of their budget deciding
\emph{what context to place in the prompt}. Retrieval-augmented generation ranks
passages, in-context learning selects demonstrations, and agentic coding tools
choose which files and conventions to surface. Across all of these, the
operative tool is a \textbf{scalar score}, lexical or embedding relevance,
mutual information, $\Vcal$-usable information~\citep{ethayarajh2022},
expected information gain, used to impose a total order and retain the top
candidates. The scalar is convenient: it sorts, thresholds, and composes. This paper asks what a
task-independent scalar ranking can and cannot represent, and answers it with a classical
apparatus from statistical decision theory.

\paragraph{What is and is not new.}
The mathematics is classical: the garbling order, the Blackwell--Sherman--Stein equivalence,
Le~Cam's deficiency. So are several of the phenomena, each in its own literature: that utility
rather than topical relevance is the right target~\citep{zhang2026utility} and is
model-dependent~\citep{zhang2025llmutility}; that adding sources can lower accuracy while coverage
saturates~\citep{dong2013lessismore}; that rerankers are steered by lexical
similarity~\citep{hagstrom2025lexical}; that keeping a non-dominated set is already an operator
over heuristic scores~\citep{skylinerag2026}; and that the Blackwell and Le~Cam apparatus was
brought to inference-time context selection concurrently with this work, over which we claim no
priority~\citep{alpila2026}. Section~\ref{sec:related} treats each in turn. The gap is that none of them
gives the order itself an object or a test: cross-task non-transfer is described as a nuisance
rather than read as a partial order, and no finite-sample procedure decides on a live model
whether two particular sources are incomparable. That is what C1--C3 below supply.

One gap needs care. Blackwell's theorem is about the \emph{best possible} use
of a source, but every number we measure comes from one fixed model: $\PASS_M(W,T) =
\mathbb{E}[v_T(\delta_M(T,w))]$, the pass rate of a single rule $\delta_M$ that is not optimal. So
we state the order twice, for the ideal user and for the fixed model, and prove a one-way bridging
lemma whose hypotheses are assumed, not measured; our sources' structural incomparability rests
instead on their construction (see Section~\ref{sec:order}); and we call our estimator a
\emph{value-deficiency surrogate}, not a Le~Cam deficiency (see Section~\ref{sec:estimator}).
\paragraph{Contributions.} The paper makes one claim, that the order over context sources is
\emph{partial} rather than total, and contributes the three pieces that claim needs: what follows
from it, the instrument that makes it testable, and the evidence that it holds.
\begin{enumerate}
  \item[\textbf{(C1)}] \textbf{Theory: the order is partial, and no single per-source score survives it}
  (see Sections~\ref{sec:order} and~\ref{sec:incomparability}). We formalize context sources as statistical
  experiments on the task's latent requirement, instantiate the Blackwell garbling order with its
  for-all-tasks dominance guarantee via the Blackwell--Sherman--Stein theorem, define the
  $\delta_M$-restricted order the experiments probe, and prove a one-way bridging lemma between
  them. What follows from taking \emph{incomparability} as the object is an impossibility:
  Blackwell-incomparable sources cannot be ranked by \emph{any} single per-source score
  $\varphi(W)$, relevance or utility, for all tasks (Theorem~\ref{thm:incomparable}), with the
  query-conditioned topical case isolated separately (Proposition~\ref{prop:trap-constrained}).
  Information retrieval has long argued that no single fixed document score is optimal once
  documents interact (see Section~\ref{sec:related-ir}); we derive that as a theorem in the Blackwell frame
  and name the exact structural condition under which it bites.
  \item[\textbf{(C2)}] \textbf{Verification: a measurable deficiency surrogate with finite-sample
  guarantees} (see Section~\ref{sec:estimator}). We define the \emph{population} gap
  $d_{M,\Dcal}(W_1,W_2) = \max\!\big(0,\,
  \sup_{T\in\Dcal}[\PASS_M(W_2,T) - \PASS_M(W_1,T)]\big)$ together with its plug-in estimate
  $\dhat_{\Dcal}$, a
  decision-restricted value-deficiency surrogate (named as such, not as a Le~Cam deficiency), and a
  distribution-free uniform verification: exact Clopper--Pearson
  intervals~\citep{clopperpearson1934} at Bonferroni level~\citep{bonferroni1936}
  $\alpha = \eta/(2|\Dcal|)$, valid jointly on a single event, so that $L_{\Dcal}>0$ verifies a
  positive value gap at confidence $\geq 1-\eta$. The selection multiplicity is paid explicitly
  rather than absorbed into a single-sample sup inequality~\citep{dvoretzky1956}, which does not
  cover an argmax over distinct cells. This is what makes the partial order testable on a real
  model behind a real verifier.
  \item[\textbf{(C3)}] \textbf{Evidence: verified incomparability and scalar-ranking failure on
  live models} (see Section~\ref{sec:experiments}). Verified empirical incomparability on six models across
  four vendors; the ranker-spectrum mis-rank on a confound-controlled trap (lexical cosine, dense
  bi-encoders, and a cross-encoder all fail; an LLM listwise reranker that reads the decisive
  content escapes, exactly the topicality boundary the theory draws); and verified
  anti-monotonicity, a strict superset of a sufficient source collapsing PASS, with order,
  length-padding, and routing-instruction controls, all with the scope limits stated in
  Section~\ref{sec:limitations}.
\end{enumerate}

\section{Related Work}
\label{sec:related}
% ==========================================================================

\subsection{Scalar selection and its limits in information retrieval}
\label{sec:related-scalar}\label{sec:related-ir}

Context and demonstration selection is dominated by \emph{scalar} criteria, each inducing a total
order and a top-$k$ prefix: topical relevance, lexical or learned~\citep{rankrag2024};
$\Vcal$-usable information~\citep{ethayarajh2022,cale2025}; expected information gain and Bayesian
experimental design~\citep{bedllm2026,conformalip2025}; Shapley- and influence-based valuation of
demonstrations~\citep{demoshapley2024,inficl2024} and of retrieved
documents~\citep{nematov2025shapley}; perplexity-reduction utility~\citep{dai2025seper}; and
binary sufficient-context detection~\citep{sufficientcontext2024}. Each collapses the comparison
of two sources to one real number, so each is an instance of the excluded class rather than a
competitor: Theorem~\ref{thm:incomparable} covers the query-independent ones, and
Proposition~\ref{prop:trap-constrained} the topical query-conditioned ones that meet its
hypotheses. For the closest neighbour, $\Vcal$-usable information, we prove Blackwell-monotonicity
(Proposition~\ref{prop:vinfo-monotone}); for mutual information and fixed-prior EIG it follows from
data processing; for a fixed decoder's perplexity-gap we claim nothing
(Remark~\ref{rem:vinfo-scope}). Calibration does not change the class: conformal context
filtering~\citep{chakraborty2026conformal} calibrates a threshold \emph{on} a scalar and inherits
its total order, and scorers of equal ranking quality can retain different document
sets~\citep{frohmann2026orderconsistent}. Identifying a non-dominated set from noisy samples is
classical in the bandit literature~\citep{auer2016pareto}; what is new here is the object it runs
on, (model, verifier, task-battery) triples, not the statistical machinery.

Retrieval has itself moved from relevance to \emph{utility}~\citep{zhang2026utility}, which is
model-specific~\citep{zhang2025llmutility} and depends on which other passages are
present~\citep{jain2025contextualutility}. That is the same diagnosis from the other side, and
this paper is its formal boundary. Utility re-measured per task by running the model is not a
fixed per-source score but the probe our estimator is built from; utility \emph{predicted} by a
learned scorer is a number again, and falls under whichever of the two results applies. Reading
the decisive coordinate is one way out, the listwise boundary; reading public task metadata is
another (Remark~\ref{rem:trapscope}). Three families sit there. Listwise
rerankers~\citep{sun2023rankgpt} and learned set selectors~\citep{optiset2026,rank4gen2026} are
query-conditioned \emph{set} functions, outside the theorem's scope but carrying no dominance
guarantee. Skyline selection~\citep{skylinerag2026} keeps the non-dominated set, the operator the
partial order calls for, but takes dominance over heuristic per-item scores rather than task
value. Diversity-aware selection, from MMR~\citep{carbonell1998} to DPPs~\citep{ye2023ceil} and
submodular selection~\citep{pacms2026}, optimizes similarity geometry rather than verified value.
Directed-information $\gamma$-covering~\citep{huang2025gammacover} is closest in form, its
covering relation being asymmetric and information-theoretic; but it orders redundancy
\emph{between sources}, computed query-agnostically, so it prunes what another chunk predicts and
never exhibits two sources each decisive where the other fails.

The limits of scalar relevance are among the oldest themes in the field, and we sit inside that
lineage: the Probability Ranking Principle~\citep{robertson1977} is optimal only under
independence, its failure once documents interact is long documented~\citep{fuhr2008}, and
interdependence was given ranking principles of its own in portfolio
theory~\citep{wang2009portfolio} and the quantum PRP, whose ``interference'' term names exactly
this dependence~\citep{zuccon2010qprp}. The LLM-era version, relevance-maximizing retrieval
degrading answers, is measured directly~\citep{relevanceutility2025}, and the observation that
relevance does not imply \emph{sufficiency} is argued at the set level~\citep{sureRAG2026}. Our
delta is the form of the statement: a theorem in the comparison-of-experiments frame, with the
structural condition under which every query-independent scalar must mis-rank, and a verified
instance on six production models.
\subsection{Task-dependence and context degradation}
\label{sec:related-taskdep}

That added context can degrade performance is by now well documented: a single irrelevant
sentence tanks reasoning~\citep{shi2023distracted}; position matters~\citep{liu2024lost};
high-scoring distractors hurt while random noise can help~\citep{cuconasu2024noise}; retrieval
curves are inverted-U in passage count~\citep{jin2024longrag}; document count hurts at fixed
length~\citep{levy2025moredocs}; added length alone hurts~\citep{contexthurts2025}; and the effect
persists across model generations~\citep{hong2025contextrot} and agent-scaffold
components~\citep{longcontextdegrade2026}. The genus is older than language models: in data
integration, adding sources raises coverage while integration quality first rises and then
falls, so that ``less is more'': low-quality sources deteriorate the fused result rather than
bringing the expected gain, and the right move is to select a subset before
integrating~\citep{dong2013lessismore}; the lesson has since been carried explicitly to augmented language
models~\citep{halevy2023learnings}. We do not claim to discover this genus. Two differences locate
our finding inside it. Where data integration traces the harm to low-quality sources and restores
monotonicity by redesigning the fusion rule, our two sources are individually correct and
sufficient, the harm survives gross-length, block-order and formatting controls on the one model
where those controls were run and is consistent with convention routing, and the rule $\delta_M$
is a fixed model that cannot be redesigned, so the response is
selection rather than fusion. And where ``interference'' in the mechanistic RAG literature means
distractor passages steering a model, a failure recently localized and corrected in a sparse
feature space~\citep{giannetti2026interference}, and inter-context \emph{conflict} means contexts
that contradict each other~\citep{xu2024knowledgeconflicts}, our sources neither distract nor
conflict: both are true and both are needed, and the superset still collapses. Our
anti-monotonicity finding contributes the order-theoretic form of this: a strict \emph{superset} of
a sufficient source, on sources separately \emph{verified} Blackwell-incomparable, collapses PASS
under a per-task verification of the direct contrast $\PASS(W_{1+},T)<\PASS(W_1,T)$: a reversal no
monotone context-value scalar can carry. A representation-level account of when context
helps, an additive error decomposition with alignment conditions~\citep{wang2026whencontext}, is
complementary: even in its multi-context extension it characterizes \emph{when} a context
corrects the error, not an order relation between candidate sources. Pareto-incomparability of prompts along competing metrics \emph{within} a single
task~\citep{paretoprompts2025} is orthogonal to our object, incomparable \emph{sources across
tasks}.

\subsection{The comparison of experiments in machine learning}
\label{sec:related-deficiency}\label{sec:related-llmrep}\label{sec:related-foundations}

The Blackwell--Le~Cam apparatus has entered machine learning and, concurrently with this work,
inference-time context selection itself. \citet{alpila2026} formalizes the admission problem
against a \emph{frozen decoder} as minimization of Le~Cam deficiency, pairs it with the
Vereshchagin--Vit\'anyi conditional structure function for the representation problem, proves a
capacity floor below which the deficiency cannot be driven, and validates a curve-aware allocator
on seven decoders in four families; a plain-language companion states the
framing~\citep{alpila2026essay} and the artifact is released~\citep{alpila2026lmrecall}. Our
object is different, the order \emph{between two admitted sources across tasks}: we show it is partial by \emph{measuring}
mutual non-domination, derive that no single per-source score can be faithful to it, and verify a
strict superset of a sufficient source collapsing PASS, with gross-length, block-order and routing
controls run on one model, not every confound excluded. Incomparability in this sense
cannot arise inside a single declared decision problem, so its absence there is a different
question rather than a gap.

A second line is training-\emph{dataset} valuation. \citet{zheng2024pmi} order datasets by
Blackwell informativeness and show that the mutual information between the curated and the test
data is a \emph{strategy-proof} score: a curation step that garbles the data, so that
$\theta \to D \to f(D)$ is a Markov chain, cannot raise it. That is the data-processing direction,
and it is one-directional; a scalar can be monotone along the order without representing it, so
their result is compatible with ours rather than opposed to it. Their comparison is also taken
against the Bayes-optimal user of the data, ours against a fixed model rule on a task family. What
Theorem~\ref{thm:incomparable} adds is the converse question, whether any query-independent scalar
can be \emph{faithful} to the order, which a monotone score need not be once the order is partial.
Nearby uses stop short of what we do: garbling to harden LLM
evaluations~\citep{bradley2024garbling}, statistical deficiency to order training
\emph{tasks}~\citep{fosse2025}, a deficiency-induced \emph{directional} dominance in transfer
learning (no incomparability, no distribution-free bound, outside language
modeling)~\citep{akdemir2025}, comparison-of-experiments ideas in loss
design~\citep{vanrooyen2014}, and a survey of Blackwell's theorems for
AI~\citep{blackwellrep2026}. Another inference-time application sits on the other side of the
model: \citet{zhang2026blackwellagents} rank the information structures
induced by multi-agent protocols, showing that voting and debate are no more informative than the
agents' pooled private information and identifying Bayesian pooled-posterior maximisation as the
Blackwell upper bound on any such protocol. That is a dominance statement about how several
models' signals combine; ours is an incomparability statement about which single source one model
is given, so the two orders are taken over different objects and neither implies the other.
\subsection{Where the two results land in the design space}
\label{sec:related-designspace}

Sorting the methods above on three axes, whether a method is cheap enough to run at retrieval
scale, whether it conditions on the task, and whether it can represent a non-dominated \emph{set}
rather than a ranking, makes the pattern uniform. Every method cheap enough to precompute emits
one number per item, however that number is produced: late interaction over multi-vector
representations~\citep{khattab2020colbert} and retrievers supervised by the language model
itself~\citep{guu2020realm,shi2023replug} are scored per item no less than lexical relevance is.
All of them therefore fall under Theorem~\ref{thm:incomparable} when that number is fixed across
tasks. The methods that escape do so either by reading the decisive content per candidate, which
costs a model call, or by routing on public task metadata, which
Proposition~\ref{prop:trap-constrained} does not exclude (Remark~\ref{rem:trapscope}). No prior
family is both cheap and faithful to the partial order; that empty cell is the open problem this
paper isolates; the verified non-dominated set pays probe cost to sit in it, and what that cost
buys is a verified relation \emph{between} the candidates, not a guarantee about any selector
built on the set.
\section{Formalization}
\label{sec:formalization}
% ==========================================================================

We model the choice of \emph{what context to supply} a language model as a comparison of
statistical experiments on the task's latent requirement. This section fixes the objects and
separates two decision rules that the informal literature silently conflates: the
\emph{Bayes-optimal} rule, against which the classical Blackwell order is defined, and the
\emph{fixed model} rule, which every empirical quantity in this paper measures.

\subsection{Tasks, latent requirements, and context sources}

A \emph{task} $T$ fixes a latent requirement $S_T$, the object a deterministic verifier
$v_T$ checks (e.g.\ the intended program behaviour). We take $S_T$ to be a \emph{vector of
coordinates}
\begin{equation}
\label{eq:coordinates}
S \;=\; (S_1, S_2, \dots, S_m) \;\in\; \Scal \;=\; \Scal_1 \times \cdots \times \Scal_m,
\end{equation}
where each coordinate $S_j$ encodes one logically independent requirement. Modelling $S$ as a
product of coordinates rather than an opaque atom is what makes the experiment model well posed
for fixed-string sources (Section~\ref{subsec:sources}, Lemma~\ref{lem:noref}).

\begin{definition}[Context source as an experiment]
\label{def:source}
A \emph{context source} $W$ is a Markov kernel $\kappa_W : \Scal \to \Delta(\Wcal)$,
i.e.\ a statistical experiment indexed by the latent parameter $S$, emitting a signal
$w \sim \kappa_W(\cdot \mid S)$ in a signal alphabet $\Wcal$ (the source's text). The
experiment is identified with its kernel; the sample space is $\Wcal$ and the observed
datum is the supplied text $w$.
\end{definition}

\begin{definition}[Decision rules and PASS]
\label{def:decision}
A \emph{decision rule} is a (possibly randomized) map $\delta : (T,w) \mapsto \widehat S$
producing a candidate solution. Utility is the binary verifier $u(\widehat S, S) = v_T(\widehat S,
S) \in \{0,1\}$, which scores the candidate against the convention in force: the same answer
passes under one convention and fails under another, which is why the second argument cannot be
dropped. Two decision rules matter:
\begin{enumerate}
  \item[(i)] the \emph{model rule} $\delta_M$ realized by a fixed language model $M$ at a fixed
    decoding configuration $\theta$ (model weights and sampling parameters; see
    Section~\ref{subsec:theta}). Its realized pass rate on task $T$ under source $W$ is
    \begin{equation}
    \label{eq:pass}
    \PASS_M(W,T;s) \;:=\; \mathbb E\big[\, v_T\!\big(\delta_M(T,w),\,s\big)\,\big],
    \qquad w \sim \kappa_W(\cdot \mid s),
    \end{equation}
    written $\PASS_M(W,T) := \PASS_M(W,T;S_T)$ at the single realized convention $S_T$, which is
    the quantity every measurement in this paper reports;
  \item[(ii)] the \emph{Bayes rule} $\delta^\star_{T}$, the utility-optimal rule for task $T$
    under a prior $\mu_T$ on $\Scal$ (the task family's distribution over private conventions),
    achieving the optimal value
    \begin{equation}
    \label{eq:vstar}
    V^\star(W,T) \;:=\; \sup_{\delta}\ \mathbb E_{S\sim\mu_T}\,
      \mathbb E\big[\, v_T\!\big(\delta(T,w),\,S\big)\,\big],
    \qquad w \sim \kappa_W(\cdot \mid S).
    \end{equation}
\end{enumerate}
\end{definition}

\begin{remark}[The two quantities are taken under different measures]
\label{rem:measures}
$\PASS_M$ in \eqref{eq:pass} is \emph{conditional on one latent state}: the expectation runs over
the source kernel and the decoder with $S$ held at the realized convention $S_T$. $V^\star$ in
\eqref{eq:vstar} is a \emph{Bayes} value, averaged over $\mu_T$. Consequently
$V^\star(W,T)\ge \PASS_M(W,T)$ is \emph{not} automatic from optimality, and we never use it in
that form. The obstruction is elementary: let $S$ be a fair bit, let $W$ be uninformative, and let
$v_T$ reward naming $S$; the constant rule ``answer $0$'' has $\PASS_M=1$ at the state $S=0$ while
$V^\star=1/2$. Nor can the gap be closed by taking $\mu_T$ to be a point mass at $S_T$: every
guessing cap $V^\star(W,T)$ would then equal $1$ and the caps of Lemma~\ref{lem:bridge} would lose
all content. What optimality does give is the averaged statement $V^\star(W,T) \ge
\overline{\PASS}_M(W,T) := \mathbb E_{S\sim\mu_T}[\PASS_M(W,T;S)]$. Lemma~\ref{lem:bridge} is
therefore proved through the sufficiency of the winning source rather than through any such
comparison; the measured pass rates enter its proof nowhere, and neither bound a Bayes value nor
estimate a guessing cap.
\end{remark}

The distinction in Definition~\ref{def:decision} is load-bearing. Blackwell's theorem
(see Section~\ref{sec:order}) is a statement about $V^\star$; every number we report, $\PASS_M$, the
deficiency estimator of Section~\ref{sec:estimator}, the interference statistic of
Section~\ref{subsec:interference}, and the entire six-model program of Section~\ref{sec:experiments}, is a
statement about the single fixed rule $\delta_M$. We therefore develop the order in two
registers and prove an explicit bridge between them (Lemma~\ref{lem:bridge}).

\subsection{Sources as deterministic projection experiments}
\label{subsec:sources}

In our instantiation each context source is a \emph{fixed string}. Reading $\kappa_W(\cdot\mid S)$
as a constant kernel $\delta_{w_0}$ independent of $S$ is degenerate: such a kernel is
Blackwell-equivalent to the null experiment, carries zero information, and induces the trivial
$\sigma$-algebra, which would make any garbling argument vacuous. We instead model each fixed
source as a \emph{deterministic experiment that observes a projection of the coordinate
vector}~\eqref{eq:coordinates}.

\begin{definition}[Projection sources]
\label{def:projection}
A source $W$ that reveals the coordinates indexed by a
set $A \subseteq \{1,\dots,m\}$ is the deterministic kernel
\begin{equation}
\label{eq:projkernel}
\kappa_{W}(\cdot \mid S) \;=\; \delta_{\pi_A(S)}, \qquad \pi_A(S) := (S_j)_{j\in A},
\end{equation}
i.e.\ supplying $W$ lets a decision-maker condition on $\pi_A(S)$ and on nothing outside $A$.
Write $\Fcal_W := \sigma(\pi_A)$ for the sub-$\sigma$-algebra of $\Scal$ generated by
the projection. In our instantiation $W_1$ reveals coordinate $S_1$ (the call contract,
$A_1=\{1\}$), $W_2$ reveals $S_2$ (the wire invariant, $A_2=\{2\}$), and the superset
$W_{1+} = W_2 \,{+}{+}\, W_1$ reveals both ($A_{1+}=\{1,2\}$).
\end{definition}

Under Definition~\ref{def:projection} the informativeness of a fixed string is exactly the
resolving power of its $\sigma$-algebra $\Fcal_W$. The signal alphabet is the range of the
projection, and the text ``varies with the task'' because the realized coordinate values
$\pi_A(S_T)$ differ across task instances $T$. This is what makes the comparison of
Section~\ref{sec:order} a comparison of experiments rather than a metaphor, and it is what a
rigorous treatment of deterministic sources requires~\citep{torgersen1991}.

\subsection{The conditioning parameter \texorpdfstring{$\theta$}{theta}}
\label{subsec:theta}

The model rule $\delta_M$ carries an implicit parameter $\theta$: the model's weights and decoding
configuration, equivalently its \emph{prior over conventions} acquired in pretraining. We write
$\PASS_M(\texttt{none},T)$, the model's no-context pass rate, for the part of a private convention
that $\theta$ already encodes; the value of a source is model-relative through it. When $\theta$
already ``knows'' a convention (the model can guess it without the source), that baseline is high
and $W$'s marginal contribution collapses; when the convention is genuinely unknown to $\theta$,
the baseline floors and the source has to carry the cell. We deliberately do \emph{not} write this
as a conditional mutual information $I(S;W\mid\theta)$: under Definitions~\ref{def:source}
and~\ref{def:decision} the law of $(S,W)$ is $\mu_T$ followed by $\kappa_W$ and carries no
$\theta$, so conditioning on a fixed model index would leave the mutual information unchanged and
model-\emph{in}dependent, the opposite of what is measured here; a genuinely model-relative
information quantity would need a subjective prior we neither define nor measure. This
$\theta$-dependence is not a nuisance: it is
the formal home of the \emph{model-relative value of private context} measured in
Section~\ref{sec:experiments}, where the guessability of a fixed convention spans $0\%$ to $100\%$ across
vendors. Throughout, all realized-PASS quantities are implicitly indexed by $\theta$; we suppress
it except where the model-relativity is the point.

\section{The Blackwell order over context sources}
\label{sec:order}
% ==========================================================================

With sources modeled as experiments (see Section~\ref{sec:formalization}), the classical comparison of
experiments applies to them directly: we state the order, record that it is partial, and bridge
its two registers.

\subsection{The order and its two registers}

\begin{definition}[Garbling order]
\label{def:blackwell}
$W_1 \Bord W_2$ ($W_1$ \emph{Blackwell-dominates} $W_2$) iff there is a Markov kernel
(garbling) $G : \Wcal_1 \to \Delta(\Wcal_2)$ with $\kappa_{W_2} = G \circ \kappa_{W_1}$;
i.e.\ $W_2$'s signal is a noised, post-processed version of $W_1$'s, computable from $W_1$'s signal
alone without further access to $S$.
\end{definition}

\begin{theorem}[Blackwell--Sherman--Stein; universal dominance for the optimal rule]
\label{thm:blackwell}
Let $W_1, W_2$ be experiments on a common \emph{finite} parameter space $\Scal$ with standard
Borel signal spaces. The following are equivalent (the implication
\textup{(i)}$\Rightarrow$\textup{(ii)} needs neither finiteness nor further regularity, and is the
only direction Corollary~\ref{cor:c1} and Lemma~\ref{lem:bridge} use):
\begin{enumerate}
  \item[\textup{(i)}] $W_1 \Bord W_2$ (Definition~\ref{def:blackwell});
  \item[\textup{(ii)}] for every prior $\mu$ on $\Scal$, every finite decision space, and every
    bounded loss $\ell$, the Bayes risk under $W_1$ is no larger than under $W_2$; equivalently the
    optimal value satisfies $V^\star(W_1,T) \ge V^\star(W_2,T)$ for every task $T$ with bounded
    utility.
\end{enumerate}
Randomized decision rules are admitted on both sides; if the dominated experiment is realized with
a randomized garbling, no loss of generality is incurred by allowing randomized rules in
\textup{(ii)}.
\end{theorem}

\noindent The theorem is classical~\citep{blackwell1953,torgersen1991} and we use it as a black
box. \textup{(i)}$\Rightarrow$\textup{(ii)} holds for arbitrary $\Scal$ with no further regularity,
by simulating the garbling. We invoke the converse \textup{(ii)}$\Rightarrow$\textup{(i)} once
only, in Theorem~\ref{thm:incomparable}, and there for a finite state space, the case
\citet{blackwell1953} proves and our coordinate construction realizes; on a general state space the
converse needs the convex closure taken in the definition of
more-informativeness~\citep{khan2025blackwell}. Reading ``experiment'' as a context source (Definition~\ref{def:source}) is faithful because the
kernels of Definition~\ref{def:projection} are standard Borel, which says nothing about the
``decision problem'' reading: clause \textup{(ii)} quantifies over \emph{all} bounded utilities,
whereas the tasks we can execute are only the binary-verifier subclass $v_T\in\{0,1\}$ of
Definition~\ref{def:decision}. That restriction is harmless in
\textup{(i)}$\Rightarrow$\textup{(ii)} but not in the converse, whose witness need not be binary;
it costs nothing for the projection sources of Definition~\ref{def:projection}, whose binary
witnesses are exhibited in the proof of Lemma~\ref{lem:bridge}\textup{(a)}, and beyond them it is
a scope limit of our presentation, not a property of the theorem.

\begin{corollary}[Universal context dominance, C1]
\label{cor:c1}
If $W_1 \Bord W_2$ then, for the \emph{optimal} user, supplying $W_1$ is at least as good as
supplying $W_2$ on \emph{every} task, prior, and bounded utility, a decision-independent,
for-all-tasks guarantee that no task-specific scalar score (relevance, mutual information,
$\Vcal$-usable information) provides.
\end{corollary}

\begin{remark}[Preorder on kernels; ``partial'' means not total]
\label{rem:partial}
On the class of all experiments $\Bord$ is reflexive and transitive but not antisymmetric, since
two experiments can garble each other without being equal, so it is a \emph{preorder} and the
induced partial order lives on Blackwell-equivalence classes~\citep{blackwell1953}. Throughout,
``partial'' means \emph{not total}: there exist experiments $V, V'$ with neither $V \Bord V'$ nor
$V' \Bord V$, and on that class the order is not even a
lattice~\citep{bertschinger2014nolattice,torgersen1991}. (The bound variables here are not the
paper's named sources: our own projection family is better behaved, and the next subsection shows
$\Bord$ is antisymmetric on it with the induced order the Boolean lattice on coordinate sets,
Lemma~\ref{lem:noref}(a).) Incomparability survives on that family and is exactly the regime our
experiments target. One caution for what follows: $\PASS_M$ is \emph{not} an invariant of a
Blackwell-equivalence class, and it need not be: a rule keyed to surface form can prefer
differently between two experiments that garble each other. The padding arm
$W_{\mathrm{pad}}$ of Appendix~\ref{app:record} reveals no coordinate any verifier checks, so it
is Blackwell-equivalent to $W_1$, yet the two do not score alike: $40/40$ against $31/40$ on
\texttt{api\_argorder}, a difference whose two-sided $90\%$ interval $[+0.0202,+0.3846]$ excludes
zero, and $40/40$ against $39/40$ on \texttt{api\_post\_ok}, where it does not. One cell therefore
certifies an instance and the other only illustrates the possibility. Either way the
$\delta_M$-restricted order of Section~\ref{subsec:bridge} is not read on the quotient.
\end{remark}

\subsection{Deterministic sources: incomparability via \texorpdfstring{$\sigma$}{sigma}-algebra non-refinement}

For deterministic projection sources (Definition~\ref{def:projection}) the garbling order reduces
to refinement of the generated $\sigma$-algebras, which makes incomparability checkable by a
purely structural argument rather than by an empirical divergence.

\begin{lemma}[Refinement characterization for projection sources]
\label{lem:noref}
Let $W_A, W_B$ be projection sources revealing coordinate sets $A,B$
(Definition~\ref{def:projection}), with coordinates $S_1,\dots,S_m$ mutually independent under
some full-support prior and each $S_j$ non-degenerate. Then:
\begin{enumerate}
  \item[\textup{(a)}] $W_A \Bord W_B \iff \Fcal_{W_B} \subseteq \Fcal_{W_A}
    \iff B \subseteq A$;
  \item[\textup{(b)}] consequently $W_A$ and $W_B$ are Blackwell-\emph{incomparable} iff
    $A \not\subseteq B$ and $B \not\subseteq A$, i.e.\ each reveals at least one coordinate the
    other hides.
\end{enumerate}
\end{lemma}

Lemma~\ref{lem:noref} is the formal version of the garbling argument used in
Section~\ref{sec:experiments}: the call contract ($W_1$, revealing the private arg-order /
required-keyword / exception-type facts $S_1$) and the wire format ($W_2$, revealing the
cents-scale / check-digit facts $S_2$) give $A_1=\{1\}$, $A_2=\{2\}$, and neither set contains the
other, so $W_1, W_2$ are Blackwell-incomparable by construction (and $W_{1+}$, revealing
$\{1,2\}$, dominates both).

\subsection{Bridging the optimal-rule order to the fixed model}
\label{subsec:bridge}

Theorem~\ref{thm:blackwell} concerns $V^\star$; our experiments measure $\PASS_M$ for a single
fixed, generally sub-optimal rule $\delta_M$. An inequality between optimal values need not hold
for a fixed rule, and, as we show empirically, the fixed rule can even \emph{violate} monotonicity
that the optimal value obeys. We therefore introduce a $\delta_M$-restricted order.

\begin{definition}[$\delta_M$-restricted, $\Dcal$-restricted order]
\label{def:dmorder}
Fix the model rule $\delta_M$ and a finite task set $\Dcal$. Say $W_1 \succeq_{M,\Dcal} W_2$ iff
$\PASS_M(W_1,T) \ge \PASS_M(W_2,T)$ for every $T \in \Dcal$. Call $W_1, W_2$
\emph{$(M,\Dcal)$-incomparable} iff $W_1 \not\succeq_{M,\Dcal} W_2$ and $W_2 \not\succeq_{M,\Dcal} W_1$, i.e.\
each strictly out-performs the other on some task in $\Dcal$.
\end{definition}

$\succeq_{M,\Dcal}$ is the order our verification measures. It is decision-restricted (one fixed
rule) and distribution-restricted (a fixed finite $\Dcal$); within those restrictions it is still a
genuine, \emph{for-all-tasks-in-$\Dcal$} dominance statement, not a scalar.

\begin{lemma}[One-way bridge under coordinate separation]
\label{lem:bridge}
Neither order implies the other unconditionally; each direction of the bridge carries an explicit
hypothesis.
\begin{enumerate}
  \item[\textup{(a)}] Let $W_1, W_2$ be projection sources revealing coordinate sets $A_1, A_2$
    (Definition~\ref{def:projection}), and let $T_a, T_b \in \Dcal$ be tasks whose
    verifier-decisive coordinates lie in $A_1 \setminus A_2$ and $A_2 \setminus A_1$
    respectively, each verifier being determined by its decisive coordinate together with facts
    known $\mu_T$-almost surely, and $\mu_T$-almost surely accepting some action measurable in that
    coordinate and those facts (\emph{sufficiency and solvability under the informed source};
    solvability is not implied by the dependence). Let the
    \emph{guessing caps} $g_a := V^\star(W_2, T_a)$ and $g_b := V^\star(W_1, T_b)$ be the Bayes
    values \eqref{eq:vstar} attainable \emph{without} the decisive coordinate. If $g_a < 1$ and
    $g_b < 1$, so that neither deprived source determines the coordinate its task turns on, then
    $W_1, W_2$ are Blackwell-incomparable. The caps are hypotheses of this criterion, not
    quantities the experiments determine. Per cell, Section~\ref{sec:experiments} reports a
    crossover between the same fixed rule's \emph{realized} rates,
    $\PASS_M(W_1,T_a) > \PASS_M(W_2,T_a)$ and $\PASS_M(W_2,T_b) > \PASS_M(W_1,T_b)$; since
    $\PASS_M$ is state-conditional and $V^\star$ a Bayes value, such a comparison neither
    estimates nor bounds $g_a$ or $g_b$, though it is consistent with $g_a, g_b < 1$
    (Remark~\ref{rem:measures}); we nowhere report the cap conditions as empirically verified.
  \item[\textup{(b)}] The converse fails in general: Blackwell incomparability concerns $V^\star$,
    and a fixed sub-optimal $\delta_M$ may fail to realize the optimal-value crossover on $\Dcal$.
    It holds under the value-attainment hypothesis (Assumption~\ref{ass:attain}).
\end{enumerate}
\end{lemma}

\begin{remark}[What the caps buy, and what they do not]
\label{rem:capsrole}
Neither hypothesis of \textup{(a)}, separation or the caps, can be dropped \emph{from this
criterion}. They are not preconditions of structural incomparability as such: for the sources
this paper measures, Lemma~\ref{lem:noref} already separates $W_1$ from $W_2$ by coordinate
non-refinement, with no caps at all. Lemma~\ref{lem:bridge}\textup{(a)} is a different route to
the same conclusion \emph{within the same projection setting}: it argues from Bayes values rather
than from $\sigma$-algebras, and the caps are what that argument costs. It is not a generalization
to arbitrary sources; a criterion for those would be a separate statement we do not prove. What the caps do here is show why a $\PASS_M$ crossover alone proves nothing:
$(W_1, W_{1+})$ is $(M,\Dcal)$-incomparable on the measured cells ($W_1$ wins the API cells,
$W_{1+}$ the encoding cell) yet strictly Blackwell-\emph{comparable} by construction
($W_{1+} \Bord W_1$, the superset revealing one further independent non-degenerate coordinate),
precisely because the deprived-side premise fails there: $W_{1+}$ contains $W_1$'s coordinate, so
the API-side cap is not small. A bare $\PASS_M$ crossover, with neither
premise verified, certifies nothing structural in \emph{either} direction. It is equally
consistent with genuine incomparability under optimal play (two sources revealing independent
coordinates cross even when each side plays optimally) and with a merely incoherent rule
(Theorem~\ref{thm:antimono}). The two cases should not be run together. $(W_1,W_{1+})$ is a
\emph{strict comparability} whose $\PASS_M$ preferences nonetheless oppose; the distinct
phenomenon of a rule preferring differently between two \emph{equivalent} experiments is
illustrated by the padding pair $(W_1,W_{\mathrm{pad}})$, where the added block carries no
coordinate any verifier reads (Remark~\ref{rem:partial}). That a representation-sensitive decoder
\emph{can} do this in general is a structural observation, not something our single measured
difference certifies. Nor is the projection construction \emph{necessary} for
incomparability: it is the cleanest sufficient condition we know, and the one our sources
realize.
\end{remark}

\begin{assumption}[Realized cross-advantage on the witnessing task pair]
\label{ass:attain}
Let $(T_a,T_b)$ be an \emph{ordered pair of named tasks}. Say $\delta_M$ \emph{attains value on}
$(T_a,T_b)$ with margin $\gamma>0$ if
$\PASS_M(W_1,T_a) - \PASS_M(W_2,T_a) \ge \gamma$ and
$\PASS_M(W_2,T_b) - \PASS_M(W_1,T_b) \ge \gamma$; i.e.\ the fixed model actually exploits each
source's private coordinate on the task that requires it. Despite the historical name we keep for
the label, the condition is a statement about \emph{realized} pass rates only: it asserts nothing
about the supremum in \eqref{eq:vstar} being attained, and no design can compel a model to satisfy
it. The hypothesis is always asserted of an
explicitly named pair: it does \emph{not} assert that some such pair exists somewhere in $\Dcal$,
and attainment on one pair implies nothing about attainment on another. If $\delta_M$ attains
value on a pair with $\{T_a,T_b\}\subseteq \Dcal$, then $W_1$ and $W_2$ are
$(M,\Dcal)$-incomparable.
\end{assumption}

The three objects do different jobs. Lemma~\ref{lem:noref} establishes structural incomparability
for the specified projection sources, with no prior, no caps and no measurement;
Lemma~\ref{lem:bridge} is a \emph{conditional} Bayes-value separation criterion whose guessing caps
are assumptions, never estimates recovered from the observed state-conditional $\PASS_M$ rates;
Assumption~\ref{ass:attain} concerns realized cross-advantage on named tasks, which the
experiments assess directly.

\section{The incomparability theorem}
\label{sec:incomparability}
% ==========================================================================

Section~\ref{sec:order} showed the order is partial; we now establish the consequence that motivates the
whole paper: no scalar can rank a Blackwell-incomparable pair. We \emph{split} the claim: a theorem
for query-\emph{independent} source scores $\varphi(W)$, and a separate, explicitly empirical
statement for query-\emph{conditioned} scores $\varphi(W,T)$, the relevance score practitioners
actually use; the two must not be conflated.

\subsection{Query-independent scores: the theorem}

\begin{theorem}[No query-independent scalar ranks incomparable sources, C1]
\label{thm:incomparable}
Let $\Scal$ be finite and let $W_1, W_2$ be Blackwell-incomparable. (Finiteness is used only to
invoke the converse direction of Theorem~\ref{thm:blackwell}, which turns incomparability into the
existence of the witness tasks; it holds for our coordinate construction, and for projection
sources the witnesses are exhibited directly in the proof of Lemma~\ref{lem:bridge}, so no
converse is needed there.) Let $\varphi : \{\text{sources}\} \to \mathbb R$ be any
\emph{query-independent} scalar score (a single number per source: relevance to a fixed corpus,
mutual information $I(S;W)$, $\Vcal$-usable information, perplexity-gap, expected information gain
under a fixed prior). Being real-valued, $\varphi$ totally \emph{preorders} sources; it need not order them strictly,
since $\varphi(W_1)=\varphi(W_2)$ is permitted. Call $\varphi$ \emph{faithful on a task $T$} if the
source strictly preferred on $T$ receives the strictly larger $\varphi$-value, so a tie is a
failure; a task-independent tie-breaking rule fixed in advance reduces ties to the strict case,
leaving the conclusion unchanged. Then there exist tasks $T_a, T_b$ such that $\varphi$ is
unfaithful to the optimal-value order on at least one of them, the witnesses being bounded-utility
decision problems from Theorem~\ref{thm:blackwell}\textup{(ii)}, not necessarily binary verifiers
(Definition~\ref{def:decision}), though they can be taken binary for projection sources (proof of
Lemma~\ref{lem:bridge}\textup{(a)}). If moreover $\delta_M$ attains value on \emph{that same} pair
$(T_a,T_b)$ (Assumption~\ref{ass:attain}), $\varphi$ is likewise unfaithful to the
realized-$\PASS_M$ order on at least one of $T_a, T_b$. More generally, attainment on \emph{any}
named pair $(T_a', T_b')$ yields $\PASS_M$-disagreement on at least one of $T_a', T_b'$ by the same
argument; the two conclusions concern their own witness pairs and do not transfer between them.
\end{theorem}

\begin{remark}[Scope]
\label{rem:c2scope}
Theorem~\ref{thm:incomparable} rules out exactly the class of \emph{source-level} scalars: any
$\varphi$ that is a fixed number per source, regardless of task. $\Vcal$-usable information, mutual
information, perplexity-gap, and (fixed-prior) EIG all live in this class, so they are corollary
victims of the theorem, not competitors (Proposition~\ref{prop:vinfo-monotone}).
\end{remark}

\begin{proposition}[$\Vcal$-usable information is Blackwell-monotone]
\label{prop:vinfo-monotone}
Let $\Vcal$-usable information $I_{\Vcal}(W\!\to\! S)$ be defined, after
\citet{ethayarajh2022}, as the reduction in expected predictive risk of the best predictor
in a fixed family $\Vcal$ when given the signal $w$ versus the null signal. If $W_1 \Bord W_2$
and the predictor family $\Vcal$ is closed under pre-composition with measurable garblings, then
$I_{\Vcal}(W_1\!\to\! S) \ge I_{\Vcal}(W_2\!\to\! S)$. Hence $I_{\Vcal}$ is a Blackwell-monotone
scalar: it respects $\Bord$ but collapses it to one real number.
\end{proposition}

\begin{remark}[Scope of Proposition~\ref{prop:vinfo-monotone}]
\label{rem:vinfo-scope}
The closure hypothesis (a family closed under pre-composition with garblings) is the natural
sufficient condition and holds for predictor families rich enough to apply a fixed measurable
post-processing; for narrower families monotonicity may fail and we do not claim it. We prove
monotonicity for the closest neighbour, $\Vcal$-usable information. For mutual information and
fixed-prior EIG the analogue is not a conjecture but immediate from data processing, the direction
\citet{zheng2024pmi} use (see Section~\ref{sec:related}). A \emph{fixed} decoder's perplexity-gap is the
singleton-family case the previous sentence excludes, so we claim nothing for it.
Theorem~\ref{thm:incomparable} excludes all of them as per-source scalars regardless, which is the
only property this paper needs.
\end{remark}

\subsection{Query-conditioned scores: the relevance trap (empirical)}
\label{subsec:trap}

A query-conditioned score $\varphi(W,T)$, e.g.\ the lexical or embedding relevance that retrieval
and RAG actually deploy, induces a \emph{different} order per task and is therefore \emph{not} a
single fixed total order, so Theorem~\ref{thm:incomparable} does \emph{not} cover it. We make two
precise statements instead.

\begin{proposition}[Constrained impossibility for feature-measurable scores]
\label{prop:trap-constrained}
Suppose $\varphi(W,T)=g(\psi(W,T))$ for a fixed feature map $\psi$ that is \emph{topical}: $\psi$
is invariant to the verifier-decisive coordinate of $S_T$. Let $T_c$ be a task whose decisive
coordinate is supplied by $W_1$, so realized utility ranks $W_1\succ W_2$ on $T_c$. Parts
\textup{(a)} and \textup{(b)} are \emph{alternatives}, not a chain: their hypotheses are mutually
exclusive. They are not exhaustive of the topical class, and the conclusion below is stated only
for scores meeting one of them.
\textbf{(a) (Tie.)} If $\psi(W_1,T_c)=\psi(W_2,T_c)$ then $\varphi(W_1,T_c)=\varphi(W_2,T_c)$, so
$\varphi$ cannot rank $W_1$ strictly above $W_2$.
\textbf{(b) (Strict inversion.)} Suppose instead that $\varphi(\cdot,T_c)=g(\mathrm{ov}(\cdot,T_c))$
reads the pair through the scalar lexical-overlap feature $\mathrm{ov}$ alone, with $g$ strictly
increasing, and that $T_c$'s lexicon is saturated with $W_2$'s vocabulary in the precise sense
$\mathrm{ov}(W_2,T_c) > \mathrm{ov}(W_1,T_c)$. Then $\varphi(W_2,T_c) > \varphi(W_1,T_c)$, a strict
mis-rank. In either case $\varphi$ fails to rank $\{W_1,W_2\}$ by realized utility on $T_c$: no
topical score satisfying \textup{(a)} or \textup{(b)} ranks $\{W_1,W_2\}$ correctly on all tasks.
\end{proposition}

\begin{remark}[What Proposition~\ref{prop:trap-constrained} does not exclude]
\label{rem:trapscope}
Invariance to the decisive coordinate's \emph{value} is a weak hypothesis, and hypotheses
\textup{(a)} and \textup{(b)} do not cover every score satisfying it. A rule reading public
metadata can escape while never touching a private value. Let $S=(X,Y)$ with $X,Y$ independent,
let $W_{\mathrm{api}}$ carry the public label \texttt{api} and reveal $X$, let
$W_{\mathrm{wire}}$ carry the public label \texttt{wire} and reveal $Y$, and let $T_{\mathrm{api}}$
and $T_{\mathrm{wire}}$ need $X$ and $Y$. The score $\varphi(W,T)=\mathbf 1[\,\text{label}(W) =
\text{family}(T)\,]$ then ranks correctly on both tasks in every state, and it satisfies neither
\textup{(a)} (the labels differ, so no tie) nor \textup{(b)} (it is not an increasing function of
lexical overlap). So the proposition constrains the two named mechanisms, not the whole
query-conditioned class, and in particular it says nothing against routers built on public task
metadata. Theorem~\ref{thm:incomparable}, which concerns one fixed number per source for all
tasks, is unaffected: a router of this kind is not a per-source scalar. What the trap shows
empirically is narrower: the text-reading scorers we ran put $W_2$ above $W_1$ on it
(see Section~\ref{sec:results-misrank}). That is a measured mis-rank, not evidence that a
learned checkpoint satisfies \textup{(a)} or \textup{(b)}; only the lexical cosine meets
\textup{(b)} by construction.
\end{remark}

\begin{remark}[Why \textup{(b)} is stated for a scalar overlap score]
\label{rem:overlaponly}
Strict monotonicity in one \emph{coordinate} of a multi-feature $\psi$ does not give (b). Take
$\psi=(\mathrm{ov},\mathrm{style})$ and $\varphi=\mathrm{ov}+10\,\mathrm{style}$, which is strictly
increasing in overlap. With $\psi(W_1,T_c)=(0.2,1)$ and $\psi(W_2,T_c)=(0.9,0)$ the scores are
$10.2$ and $0.9$: overlap favours $W_2$ while the score favours $W_1$. Comparing two inputs that
differ in other features therefore needs the whole map, which is why (b) assumes $\varphi$ reads
overlap alone. The lexical cosine of Section~\ref{sec:experiments} satisfies that assumption by
construction; a learned reranker need not, which is why its behaviour is settled empirically
rather than by this proposition.
\end{remark}

Because Proposition~\ref{prop:trap-constrained} binds a query-conditioned score only when it meets
hypothesis \textup{(a)} or \textup{(b)} (Remark~\ref{rem:trapscope}), we treat the defeat of
query-conditioned relevance as an \emph{empirical} result, demonstrated for the concrete
lexical-cosine score practitioners use and for the checkpoints of Section~\ref{sec:results-misrank}. In
Section~\ref{sec:experiments} the \texttt{trap\_store\_wire} task realizes $T_c$, where the lexical
cosine and representative open-weight learned rankers---two dense bi-encoders (BGE, E5) and a
cross-encoder reranker---all mis-rank the pair (Section~\ref{sec:results-misrank},
Table~\ref{tab:rankers}), so the topical class is not a lexical strawman. The same failure is
documented in the wild: language-model re-rankers are steered by lexical similarity across NQ,
LitQA2, and DRUID~\citep{hagstrom2025lexical}, a corpus of real retrieved
contexts~\citep{hagstrom2025druid}; and semantically close but logically irrelevant passages defeat
retrievers and rerankers at scale, with a listwise evidence-reasoning agent as the
remedy~\citep{chen2026deepera}. An LLM \emph{listwise} reranker, which reads both documents and can
therefore condition on the private coordinate itself, ranks the trap correctly ($100/100$), behaviour
Proposition~\ref{prop:trap-constrained} permits rather than predicts.

\section{The decision-restricted deficiency surrogate and its uniform verification}
\label{sec:estimator}
% ==========================================================================

The impossibility of Section~\ref{sec:incomparability} concerns the idealized user of a source; every
quantity we report, by contrast, comes from a single fixed model. This section builds the
instrument that connects the two: a surrogate that measures the order on the fixed rule, and a
distribution-free verification that makes each comparison auditable on a live model.

\subsection{The surrogate and its correct name}
\label{subsec:estimator-name}

Exact garblings over text cannot be computed, and $\Bord$ is only partial, so instead we measure the
fixed-rule order of Definition~\ref{def:dmorder}. Fix the model rule $\delta_M$ and a finite task
set $\Dcal$, and define the \emph{decision-restricted value-deficiency}, the worst amount by which
$W_1$ trails $W_2$ across the tasks in $\Dcal$:
\begin{equation}
\label{eq:estimator}
d_{M,\Dcal}(W_1,W_2) \;:=\; \max\!\Big(0,\ \sup_{T\in \Dcal}\big[\PASS_M(W_2,T)-\PASS_M(W_1,T)\big]\Big),
\end{equation}
where each $\PASS_M(W,T)$ is the \emph{population} pass probability $p_{W,T}$ of \eqref{eq:pass},
so \eqref{eq:estimator} is a population functional and not a statistic; its \emph{plug-in}
estimate $\dhat_{\Dcal}$ substitutes $\hat p_{W,T} = k_{W,T}/n$ from $n$ completions per cell, the
hat marking the sample quantity throughout. In population terms $d_{M,\Dcal}(W_1,W_2)=0$ is
\emph{equivalent} to the dominance $W_1 \succeq_{M,\Dcal} W_2$ of Definition~\ref{def:dmorder},
and mutual positivity $d_{M,\Dcal}(W_1,W_2)>0 \wedge d_{M,\Dcal}(W_2,W_1)>0$ to
$(M,\Dcal)$-incomparability. Neither holds of the plug-in: at finite $n$, $\dhat_{\Dcal}=0$
certifies no dominance and $\dhat_{\Dcal}>0$ no positive population gap, both carrying sampling
error and the maximum being selected besides. Section~\ref{subsec:certificate} supplies the
missing confidence statement, and that construction, not the sign of the plug-in, is the
inferential step on which every claim we call \emph{verified} rests.

\begin{remark}[This is \emph{not} Le~Cam deficiency]
\label{rem:notlecam}
The Le~Cam deficiency of $\mathcal E$ relative to $\mathcal F$, experiments on a common state
space $\Scal$ with kernels $\kappa_{\mathcal E}(\cdot\mid s)$, $\kappa_{\mathcal F}(\cdot\mid s)$,
is the \emph{directed} quantity
\[
  \delta(\mathcal E,\mathcal F) \;:=\; \inf_{G}\ \sup_{s\in\Scal}\ 
  \big\|\, G\,\kappa_{\mathcal E}(\cdot\mid s) \;-\; \kappa_{\mathcal F}(\cdot\mid s) \,\big\|_{\mathrm{TV}},
  \qquad \|P-Q\|_{\mathrm{TV}} \;:=\; \sup_{A}\,\big|P(A)-Q(A)\big|,
\]
with $G$ ranging over Markov kernels from $\mathcal E$'s signal space to $\mathcal F$'s, so that
$\delta(\mathcal E,\mathcal F)=0$ recovers the garbling relation $\mathcal E \Bord \mathcal F$ of
Definition~\ref{def:blackwell}~\citep{lecam1964,lecam1986,torgersen1991}. Its value depends on the
direction, on the normalization above (the supremum over events; the $L_1$ form is twice it), and
on $\sup_{s}$ rather than an average against a prior on $\Scal$, so we import no constants from the
decision-theoretic reading of \citet{vanrooyen2014}, whose uniform excess-risk bound over a
\emph{normalized} bounded-loss class is tied to that normalization and unavailable under
unrestricted loss scaling. The quantity in
\eqref{eq:estimator} performs no garbling minimization and uses a single fixed rule $\delta_M$ over
a fixed finite task set; it is a one-sided value/regret gap, not a deficiency. No general inequality
relates $d_{M,\Dcal}$ to the true Le~Cam deficiency for a fixed sub-optimal rule (it can be
larger or smaller in either direction). We therefore name \eqref{eq:estimator} the
\emph{decision-restricted value-deficiency} and use ``Le~Cam deficiency'' only as the conceptual
analogy that motivates a graded relaxation of the partial order. The one direction that \emph{does}
transfer is qualitative: $d_{M,\Dcal}(W_1,W_2)=0$ realizes the for-all-tasks-in-$\Dcal$ dominance
of Definition~\ref{def:dmorder}, the measurable shadow of Corollary~\ref{cor:c1}.
\end{remark}

\subsection{The uniform verification}
\label{subsec:certificate}

The surrogate \eqref{eq:estimator} selects the \emph{argmax-gap} task, so a pointwise confidence
statement on a single task ignores the selection. We pay the multiplicity with an exact
Clopper--Pearson interval per cell and a union bound, which is distribution-free and finite-sample
valid.

\begin{proposition}[Uniform incomparability verification]
\label{prop:certificate}
Within each cell $(W,T)$ draw $n$ i.i.d.\ Bernoulli PASS outcomes (see
Assumption~\ref{ass:iid}). Let $[L_{W,T},U_{W,T}]$ be the exact (two-sided) Clopper--Pearson
interval~\citep{clopperpearson1934} for $p_{W,T}=\PASS_M(W,T)$ at level
$\alpha = \eta/(2|\Dcal|)$. By the Bonferroni/union bound~\citep{bonferroni1936} over the $2|\Dcal|$
proportions $\{p_{W_1,T},p_{W_2,T}\}_{T\in \Dcal}$, all $2|\Dcal|$ intervals hold simultaneously with
probability at least $1-\eta$. On that event,
\begin{equation}
\label{eq:LD}
L_{\Dcal}(W_1,W_2) \;:=\; \max_{T\in \Dcal}\big[\,L_{W_2,T} - U_{W_1,T}\,\big]
\end{equation}
is a $(1-\eta)$ lower confidence bound on $\sup_{T\in \Dcal}[p_{W_2,T}-p_{W_1,T}]$. Hence
$L_{\Dcal}(W_1,W_2) > 0$ \textbf{verifies} the \emph{population} statement
$d_{M,\Dcal}(W_1,W_2)>0$ at confidence $\ge 1-\eta$.
Both directions $L_{\Dcal}(W_1,W_2)$ and $L_{\Dcal}(W_2,W_1)$ read off the \emph{same} $2|\Dcal|$
intervals and so are valid on the same coverage event. Consequently, \emph{if both observed bounds
are positive}, the joint incomparability claim
$\{d_{M,\Dcal}(W_1,W_2)>0 \wedge d_{M,\Dcal}(W_2,W_1)>0\}$ holds at $\ge 1-\eta$ with no
additional correction. The condition is not decoration: coverage alone implies nothing about the
population gaps, which are identically $0$ when $W_1$ and $W_2$ are the same source. The
verification is one-sided, asserting nothing when the two bounds are not both positive, and the
guarantee is frequentist: the probability of declaring incomparability when it does not hold is at
most $\eta$, which is not a posterior probability that the fixed sources satisfy the inequality. The matching quantity
$U_{\Dcal}(W_1,W_2) := \max_{T\in \Dcal}\big[\,U_{W_2,T} - L_{W_1,T}\,\big]$ is, on the same
event, a $(1-\eta)$ \emph{upper} confidence bound on the same supremum; the dominance control
uses it to verify $d_{M,\Dcal}(W_1,W_2)=0$ up to the equivalence margin.
\end{proposition}

A naive single-sample DKW bound under-covers this supremum, because the object is a maximum of
differences of binomial means across distinct cells and the verification selects the argmax-gap
cell, so the multiplicity must be paid explicitly rather than absorbed into a single-sample
envelope (Appendix~\ref{app:proofs}); the resulting construction aligns with recent statistical
guidance for black-box LLM evaluation (Appendix~\ref{app:proofs}).


\begin{assumption}[Sampling regime]
\label{ass:iid}
The $n$ outcomes within a cell are i.i.d.\ Bernoulli draws of $v_T(\delta_M(T,w))$. Every draw is a
single completion (plus deterministic code extraction) from an independent call with no shared
state, which is what makes the binomial model of Assumption~\ref{ass:iid} reasonable rather than proved; we report
the decoding configuration in Section~\ref{sec:experiments}. Where draws are near-deterministic
($\hat p\in\{0,1\}$ stark cells) the Clopper--Pearson interval becomes one-sided but retains
nonzero width, so the verification stays conservative rather than degenerate.
\end{assumption}

\subsection{The interference verification (anti-monotonicity)}
\label{subsec:interference}

The deficiency surrogate also detects a phenomenon the optimal-value order forbids but a fixed rule
can exhibit: supplying a \emph{superset} source $W_{1+}$ (revealing strictly more coordinates than
$W_1$; Definition~\ref{def:projection}) can \emph{degrade} performance. Define the per-task
interference
\begin{equation}
\label{eq:interference}
\Psi_T \;:=\; \PASS_M(W_{1+},T) - \PASS_M(W_1,T) - \PASS_M(W_2,T) + \PASS_M(\texttt{none},T),
\end{equation}
the second-difference (interaction) of adding $W_2$ on top of $W_1$. We write the interaction as
$\Psi_T$ (rather than a symbol $I$ that would collide with mutual information $I(S;W)$). A
verified $\Delta_T<0$ on a cell whose $W_1$ arm is at ceiling is the localized statement that
``more strictly-more-informative context hurts''; $\Psi_T$ is reported alongside it as the
interaction term only (Remark~\ref{rem:psinotharm}).

\begin{proposition}[Interference verification]
\label{prop:interference}
Fix a target task $T^\star\in \Dcal$ chosen \emph{before} unblinding, and let
$\Delta_{T^\star} := \PASS_M(W_{1+},T^\star)-\PASS_M(W_1,T^\star)$ be the harm contrast. With exact
Clopper--Pearson endpoints $\mathrm{CP}_{\mathrm{lo}},\mathrm{CP}_{\mathrm{hi}}$ carrying
noncoverage at most $\alpha=\eta/2$ \emph{per endpoint} on the two arms $\{W_{1+},W_1\}$ (two
endpoints, union-bounding to $\eta$; the two unused endpoints of a two-sided interval are not
paid for),
\begin{equation}
\label{eq:deltaupper}
\overline\Delta_{T^\star} \;:=\; \mathrm{CP}_{\mathrm{hi}}(p_{W_{1+}}) - \mathrm{CP}_{\mathrm{lo}}(p_{W_1})
\end{equation}
is a $(1-\eta)$ upper confidence bound on $\Delta_{T^\star}$, and $\overline\Delta_{T^\star}\le-\tau$
verifies $\Delta_{T^\star}\le-\tau$ at confidence $\ge 1-\eta$. If instead the harmful cell is
\emph{selected} from $|\Dcal|$ candidates after unblinding, use $\alpha=\eta/(2|\Dcal|)$;
this is the same selection correction the verification applies to the deficiency surrogate
(the multiplicity is real: the selected cell is an argmax over $|\Dcal|$ noisy gaps, so a
single-sample sup inequality does not cover it), and omitting it would repeat the error we
criticize. Because
$\Delta$ reads only the two arms it contrasts, the bound is insensitive to the \texttt{none}
baseline; we still report that baseline per cell, because guessability bears on whether the source
is genuinely private and hence on the incomparability reading (see Section~\ref{subsec:theta}).
\end{proposition}

\begin{remark}[$\Psi$ is interaction, not harm]
\label{rem:psinotharm}
The second difference must not be read as a harm measure. Writing $f$ for the set function
$A\mapsto\PASS_M(W_A,T)$, the inequality $\Psi_T\le 0$ is precisely the submodularity condition for
the pair $\{W_1,W_2\}$, so a negative $\Psi_T$ is what diminishing returns look like and is
consistent with $f$ being monotone submodular. It does not imply that adding $W_2$ to $W_1$ hurt:
taking $\PASS(\texttt{none})=0$ and $\PASS(W_1)=\PASS(W_2)=\PASS(W_{1+})=1$ gives $\Psi_T=-1$ with
no degradation whatever. What the collapse violates is \emph{monotonicity}, $\Delta_T<0$, which is
the quantity we verify. In our data the two coincide in direction, and the contrast bound is
tighter than the four-term one because it spends its confidence budget on two intervals rather
than four.
\end{remark}

\subsection{Anti-monotonicity as information non-monotonicity of \texorpdfstring{$\delta_M$}{the model rule}}
\label{subsec:antimono}

A verified $\Delta_{T^\star}<0$ on a ceiling-$W_1$ cell is more than a curiosity: it is a falsification
of Blackwell superset-dominance \emph{for the fixed model rule}, and it pinpoints exactly where the
optimal-rule order (Theorem~\ref{thm:blackwell}) and the realized rule diverge.

\begin{theorem}[Information non-monotonicity of the model rule]
\label{thm:antimono}
Let $W_{1+}$ reveal a superset of $W_1$'s coordinates, so $W_{1+}\Bord W_1$
(Lemma~\ref{lem:noref}). Call a rule $\delta$ \emph{Blackwell-coherent on $T$} if its realized
pass rate does not fall when it is handed the dominating source, that is
$\PASS_\delta(W_{1+},T)\ge\PASS_\delta(W_1,T)$ at the realized state $S_T$. Coherence in this
sense costs no information, and a coherent rule exists on every task: the pruning rule
$\delta_M\circ G$, where $G$ deletes $W_2$'s block from $W_{1+}$'s signal and acts as the identity
on $W_1$'s, so that the one rule is defined on both inputs, satisfies
$\PASS_{\delta_M\circ G}(W_{1+},T)=\PASS_{\delta_M\circ G}(W_1,T)=\PASS_M(W_1,T)$ at that state,
because $G\circ\kappa_{W_{1+}}(\cdot\mid s)=\kappa_{W_1}(\cdot\mid s)$ for every $s$; no prior and
no averaging enter. The Bayes rule $\delta^\star$ is deliberately \emph{not} the exemplar here:
its value is monotone in the $\mu_T$-averaged register only, and monotonicity there is consistent
with a fall at a single state (Remark~\ref{rem:measures}). If a fixed model rule
$\delta_M$ has a task $T^\star$ with $\PASS_M(W_{1+},T^\star) <
\PASS_M(W_1,T^\star)$, then $\delta_M$ is \emph{not} Blackwell-coherent: it violates
monotonicity under the garbling order on $T^\star$. In particular no monotone scalar
context-value score can predict $\delta_M$'s behaviour on $T^\star$.
\end{theorem}

Theorem~\ref{thm:antimono} converts the empirical collapse into a structural statement: the harm is
not noise but a witness that real LLM decision rules are not Blackwell-coherent in the PASS
register, and the comparison is like-for-like: $\delta_M$ is beaten, at the same state and on the
same input, by its own pruned version $\delta_M\circ G$. The deficiency
surrogate detects this reversal because it tracks realized PASS, whereas every monotone scalar must
miss it by construction.

\subsection{Family-wise error across the verified claims}
\label{subsec:fwer}

Each verification above controls error \emph{marginally} at $\eta$ for its own claim
(incomparability via Proposition~\ref{prop:certificate}; interference via
Proposition~\ref{prop:interference}). The unit of accounting is the \emph{coverage event}, not the
claim. Every statement that is a deterministic consequence of the same $2|\Dcal|$
Clopper--Pearson intervals holds simultaneously on the event $E$ of
Proposition~\ref{prop:certificate}, and therefore \emph{jointly} at $\ge 1-\eta$ with no further
correction: this covers both incomparability directions, the dominance control
$U_{\Dcal}(\cdot,\cdot)$, whose endpoints are endpoints of those very intervals, and any per-task
strict win read off them. Adding a conclusion drawn from intervals already covered does not by
itself cost another Bonferroni factor. What does require fresh allocation is a conjunction
spanning \emph{different} events, that is, claims reading cells outside $E$ or intervals built at a
different level. The interference verification is of that kind, since it reads the $W_{1+}$ and
$W_1$ arms at $\alpha=\eta/2$ per endpoint, and the $W_{1+}$ intervals are not in the
$W_1$/$W_2$ event at all; conjunctions joining it to the incomparability family are
therefore reported as marginal per claim, and where a joint statement is wanted we allocate $\eta$
across the $C$ events involved.

\noindent The two verifications have different effective-$n$ requirements: incomparability is
carried by stark $0/1$ cells whose intervals are tight, whereas a harm contrast on a milder
collapse spends more of the budget. This is why the four-term interaction bound left Opus short of
the margin while the two-arm contrast clears it (see Section~\ref{sec:results-antimono}); the power analysis
is in Appendix~\ref{app:proofs}.

\section{Experiments}
\label{sec:experiments}
% ==========================================================================

With the order (see Section~\ref{sec:order}), its impossibility consequence (see Section~\ref{sec:incomparability}),
and the verification that measures it (see Section~\ref{sec:estimator}) in hand, we now instantiate the
theory on real language models. The design has three commitments. First, every reported number is an empirical PASS rate from live model
calls verified by an executable test harness; no value is modeled, simulated, or extrapolated.
Second, the two context sources are constructed to be \emph{Blackwell-incomparable by construction}
(see Section~\ref{sec:design}), so the incomparability theorem (Theorem~\ref{thm:incomparable}) has a
non-vacuous instance to bite on. Third, every verified claim is reported with the exact sample
size, the Clopper--Pearson endpoints, and the per-cell PASS counts from which it is derived
(see Section~\ref{sec:results}), so the verification is auditable rather than asserted.

\subsection{Design: two incomparable context sources}
\label{sec:design}

We define two \emph{private, unguessable} conventions on the \emph{same} module \texttt{ledger},
matched on every nuisance axis (length, roughly three sentences, exactly one private convention
each, same module, same task shape). Because both are on-topic for any ``ledger'' task, any lexical,
embedding, mutual-information, or $\Vcal$-usable score treats them as equally relevant
candidates, the precondition for Theorem~\ref{thm:incomparable} to apply.

\begin{description}
  \item[$W_1$, API call contract.] \texttt{ledger.post(account, amount, *, memo)}: \texttt{account}
  first, \texttt{amount} second positional, \texttt{memo} a \emph{required keyword-only} argument;
  returns an integer entry id $\ge 1$; raises \texttt{ledger.PostError} (not
  \texttt{ValueError}/\texttt{KeyError}) on failure.
  \item[$W_2$, wire-encoding invariant.] Amounts serialize to \texttt{<sign><minor-unit-digits>\#<check>},
  where $\mathrm{check} = (\text{sum of digits}) \bmod 10$; e.g.\ \$12.30 $\mapsto$ \texttt{"+1230\#6"}
  and $-\$0.07 \mapsto$ \texttt{"-7\#7"}. Decoding rejects a wrong check digit.
  \item[$W_{1+}$, literal superset.] $W_{1+} = W_2 \,{+}{+}\, W_1$, the concatenation of
  $W_2$'s signal with $W_1$'s. As a deterministic source revealing both coordinates, it
  Blackwell-dominates both $W_1$ and $W_2$ ($W_{1+} \Bord W_1$ and $W_{1+} \Bord W_2$);
  it is the anti-monotonicity / dominance probe. We also use
  $W_{1+}^{\mathrm{rev}} = W_1 \,{+}{+}\, W_2$ ($W_1$ first) as an order control.
\end{description}

\paragraph{Why incomparable (garbling argument).}
The argument is simple. From $W_2$'s wire format you cannot recover $W_1$'s private argument order,
its required \texttt{memo} keyword, or its error type; from $W_1$'s contract you cannot recover
$W_2$'s cents scale, its \texttt{\#} separator, or its mod-10 check. Each source states a fact the
other leaves out, so neither is a blurred copy of the other, and $W_1, W_2$ are incomparable. This
is exactly the coordinate picture of Section~\ref{sec:formalization}: $W_1$ and $W_2$ reveal different,
non-overlapping facts about $S$ (Lemma~\ref{lem:noref}).

\paragraph{Confound defense: the double crossover.}
The key pattern is a \emph{double crossover}, measured against a \texttt{none} baseline (no note
supplied): $W_1$ raises the API tasks but \emph{not} the encoding task, while $W_2$ raises the
encoding task but \emph{not} the API tasks. If encoding were simply ``harder,'' $W_1$ would fail to
help it and $W_2$ would still have to raise it from the same floor. In the clean carrying cells the
deprived arms floor at or near the \texttt{none} baseline, so the two task families are equally hard on
their own and any difference comes from the matching private fact, not from one family being harder;
when a model prior leaks a convention (Table~\ref{tab:percell}), we report that leakage explicitly and
do not use those cells for claims that require a near-zero baseline.

\subsection{Tasks}
\label{sec:tasks}

The full design comprises seven tasks with stub-\texttt{ledger} verifiers (return code $0 =$ PASS):
four $W_1$-decisive API tasks (\texttt{api\_post\_ok}, \texttt{api\_argorder}, \texttt{api\_error\_type},
\texttt{api\_memo\_required}), two $W_2$-decisive encoding tasks (\texttt{enc\_amount}, \texttt{dec\_amount}),
and one relevance trap (\texttt{trap\_store\_wire}). The verifier stubs a fake \texttt{ledger} that
accepts \emph{only} the exact private contract (rejecting wrong positional order, a missing
\texttt{memo=}, or the wrong exception type).

\paragraph{Verified battery.}
The verified runs use a fixed four-cell battery: \texttt{api\_post\_ok}, \texttt{api\_argorder}
(hardened so \texttt{memo} arrives through a parameter, forcing reliance on the keyword-only fact),
\texttt{enc\_amount}, and the trap \texttt{trap\_store\_wire}. We disclose this reduction explicitly:
the three remaining designed cells (\texttt{api\_error\_type}, \texttt{api\_memo\_required},
\texttt{dec\_amount}) are not part of the verified battery. The four-cell selection was made to
retain at least one $W_1$-decisive, one $W_2$-decisive, and the trap cell while keeping the
cross-model spend tractable; we report below that this is best understood as a fixed adversarial
four-cell battery, not a sampled task distribution, and we state the effective support of the
deficiency surrogate accordingly (see Section~\ref{sec:results-incomp}).

\paragraph{The relevance trap.}
The trap \texttt{trap\_store\_wire} is a constructed test of the topicality condition in Proposition~\ref{prop:trap-constrained}. Its
prompt is lexically saturated with encoding vocabulary, so a \emph{query-conditioned} lexical
relevance score ranks $W_2 > W_1$; but its graded requirement is the $W_1$ call contract (it must
post an already-encoded wire string through \texttt{post}), so realized PASS ranks $W_1 > W_2$. This
defeats the query-conditioned relevance score practitioners actually use, not merely a
query-independent ranking. We measure relevance as bag-of-words cosine $\varphi_{\mathrm{lex}}(W,T)$
between a source and the task prompt, computed \emph{before} the model is run. We use lexical
cosine as the \emph{minimal} instantiation of Proposition~\ref{prop:trap-constrained}, the
cheapest member of the topical class; stronger learned rankers (dense bi-encoders, a
cross-encoder, and an LLM listwise reranker) are tested against the same trap separately in
Section~\ref{sec:results-misrank}, while the theorem (Theorem~\ref{thm:incomparable}) is the general
claim for query-independent scalars.

\subsection{Materials and Methods}
\label{sec:methodology}

\paragraph{Models and vendors.}
We evaluate six models across four vendors: Anthropic Haiku-4.5, Sonnet-4.6, and Opus-4.8; OpenAI
GPT-5.5; DeepSeek-V4-Pro; and Moonshot Kimi-K2.6. Nothing in this paper is trained or fine-tuned:
all six are fixed production systems accessed through their public APIs, so there are no training
or validation curves to report; the released measurement record, per-cell PASS tables, exact
intervals, and raw run logs, is the complete empirical object.

\paragraph{Harness and arms.}
The harness (\texttt{harness/measure\_blackwell.py}; released with all run logs at
\url{https://github.com/abilous-ti/blackwell-llm-context}) is Python-standard-library only (zero
external dependencies); it computes $\dhat_{\Dcal}$ in both directions, the uniform
Clopper--Pearson/Bonferroni verification, the interference verification, and the lexical relevance
score, and it implements the launchers for the Anthropic Messages API, the Azure Responses API,
and OpenAI-compatible chat completions. Each cell is run under the arms $\{\texttt{none}, W_1, W_2,
W_{1+}\}$. PASS is measured over $n$ completions per cell.

\paragraph{One turn budget, one transport.}
Every model gets a single completion per attempt, from which we extract the candidate code and
grade it. All six are reached the same way: a single HTTP request the harness composes itself,
carrying only the task prompt, with no system prompt of our own and no tools available to the
model. The Anthropic models are served over the Messages API and the other three over an
OpenAI-style endpoint, but in both cases the request is one pass with no agentic exploration, so
the model must use what it is given. Cross-vendor \emph{magnitudes} therefore no
longer carry a transport confound, though they remain subject to the ordinary caution that
vendors' models differ in ways we do not control (see Section~\ref{sec:limitations}). The claims the paper
verifies are within-model comparisons between arms, where any remaining request-level detail is
held fixed and cancels.

\paragraph{Statistical reporting.}
Each cell is $n=40$ independent completions scored by an executable verifier and summarised as a
count; the arms within a cell are separate completions, and each draw is an independent call with
no shared state (Assumption~\ref{ass:iid}). Uncertainty is carried by exact Clopper--Pearson
intervals rather than a normal approximation, which at $n=40$ and proportions near $0$ or $1$ is
where the approximation is worst (see Section~\ref{subsec:power}). Multiplicity is paid explicitly by a union
bound whose family is stated with each claim, at confidence budget $\eta = 0.10$, so the statements
\emph{within} a family hold jointly with probability $\ge 1-\eta$. Incomparability spends
$\alpha = \eta/(2|\Dcal|)$ over the $2|\Dcal|$ proportions $\{p_{W_1,T}, p_{W_2,T}\}_{T\in \Dcal}$,
and both directions are read off those same intervals (Proposition~\ref{prop:certificate}); a harm
contrast spends $\alpha = \eta/2$ on its two arms $\{W_{1+},W_1\}$ and verifies $\Delta_T \le -\tau$
at $\tau = 0.30$ through the upper bound $\overline\Delta_T$
(Proposition~\ref{prop:interference}), the four-term $\Psi_T$ being reported descriptively only
(Remark~\ref{rem:psinotharm}). Each verification is thus controlled marginally at $\eta$; we do not
claim joint control across the incomparability, dominance and interference families drawn from a
single run (see Sections~\ref{subsec:fwer} and~\ref{sec:limitations}). At $\hat p=0$ or $\hat p=1$ the interval
becomes one-sided but does not degenerate to a point: at $n=40$ and the level
Figure~\ref{fig:hasse} uses, $0/40$ gives $[0,\,0.1281]$ and $40/40$ gives $[0.8719,\,1]$. It is that
residual width a crossing must beat, which is why the stark $100\%/0\%$ cells verify at this $n$
while intermediate proportions would need a larger one. Results whose intervals do not separate are
labeled \emph{reproduced but not verified} and are never used as evidence; the protocol reports its
own insufficiency rather than hiding it. We report no $p$-values and fit no model to the data.

\paragraph{Reproducibility artifacts.}
The measurement harness, every per-cell run log, every result file and the analysis scripts are
released (Data Availability Statement). \texttt{results/MANIFEST.md} pins each record by SHA-256
and maps every table and figure to the files it is computed from, and
\texttt{harness/diag/check\_regimes.py} reports the transport and turn budget of each cited run
with the evidence for it. It is an inventory, not a proof: it checks only the runs on a fixed list,
and matches the disclosure wording against the manuscript globally rather than to the run it
describes. Appendix~\ref{app:repro} gives the decoding configuration, the
retry and outage policy, and the cells that were re-measured, with why.

\paragraph{Why these constants.}
Both constants were fixed before the runs and neither is load-bearing. $\eta=0.10$ is a
conventional $90\%$ family level, and the headline separations are near-$0\%$ against near-$100\%$,
so tightening it does not move the verified conclusions. $\tau=0.30$ is an a priori materiality
threshold: to count, interference must destroy at least $30$ PASS points, well above the interval
widths at $n=40$, so noise cannot clear it. The data show the threshold doing real work. Verified
collapses clear it with upper bounds from $-0.38$ to $-0.85$ (Table~\ref{tab:interference}), and
the superset falls below the character-matched padding arm at $-0.85$ on both control cells. What
shows the choice is not load-bearing is that
the verdict barely moves with it: every one of the twelve contrasts clears marginally for any
$\tau$ from $0.10$ to $0.30$, and eleven of twelve up to $0.50$, so halving or raising the
threshold leaves the conclusion intact. The margin is set by DeepSeek's two cells, at $-0.384$
and $-0.540$, which are the first to drop out as $\tau$ rises.

\paragraph{What the intervals do not cover.}
The Clopper--Pearson intervals carry sampling error under Assumption~\ref{ass:iid}, a fixed success
probability per cell. They carry nothing else, and two components outside them are larger than they
are. \emph{Model drift}: successive re-measurements moved Opus's \texttt{api\_post\_ok} superset arm
from $38\%$ to $12\%$ and then to $3\%$, and DeepSeek's $W_1$ arm from $75\%$ to $43\%$, both far
outside the nominal intervals for those cells. \emph{Prompt wording}: an earlier record traced a $100\%\to52\%$ swing
on one cell to the prompt naming the call as \texttt{ledger.post}, an effect an order of magnitude
wider than any interval here, and each cell has exactly one prompt, so this component is not
modelled at all. Every verified quantity is therefore an inference about a (model snapshot, prompt,
default decoder, collection window) tuple, indexed by $\theta$ (see Section~\ref{subsec:theta}) and by
the run it was drawn in, not a property of a vendor's model line. We read that as a weakness: the
re-measurement bounds the drift component empirically, and the direction of every verdict survived
it.
\paragraph{Provenance.}
Every cell of the six-model grid is read from that model's own complete run, so each harm contrast
compares two arms collected in one window; the same holds for the four behavioural controls, which
share a single run, and for the second source pair. One substitution remains: both the $W_1$ and
the $W_2$ conditions of GPT-5.5's \texttt{trap\_store\_wire} task are taken from the retained,
transport-clean re-measurement, at $40/40$ and $0/40$, because the base run logged an HTTP~500
there. Those two therefore share a window with each other; what crosses windows is that task
against GPT-5.5's other cells, where a shared model name and transport do not establish a shared
decoder (Appendix~\ref{app:repro}). Raw completions were
retained for three of the six models (Appendix~\ref{app:audit}); for the other three the record is
aggregate-only. \texttt{results/MANIFEST.md} gives the run, and so the window, behind each number.

\subsubsection{Incomparability verified on all six models}
\label{sec:results-incomp}


On every model the empirical deficiency is mutually positive, $\dhat_{\Dcal}(W_1,W_2) > 0$ and
$\dhat_{\Dcal}(W_2,W_1) > 0$, and the uniform lower bounds $L_{\Dcal}$ in both directions clear zero,
verifying empirical incomparability at $\ge 90\%$ (Table~\ref{tab:consolidated}). The crossover is stark:
$W_1$ solves the API and trap cells and fails encoding, while $W_2$ solves encoding and fails the API
and trap cells. For Haiku at $n=40$ the two directions are attained by different cells:
$L_{\Dcal}(W_2,W_1)=+0.762$ by \texttt{api\_post\_ok}, where $W_1$ passes $40/40$ and $W_2$ none,
and $L_{\Dcal}(W_1,W_2)=+0.226$ by \texttt{enc\_amount}, where $W_2$ passes $22/40$ and $W_1$
none. The encoding contrast is the binding direction, narrower because $W_2$ reaches only
$22/40$ there.

\paragraph{The six-model claim, made jointly.} Proposition~\ref{prop:certificate} controls the
$2|\Dcal|$ intervals of \emph{one} model's run, so the per-model verifications above are each at
$\ge 1-\eta$ and their conjunction across the roster is not. Rather than leave the six-model
statement marginal we pay for it: allocating $\eta$ across the six runs, i.e.\ per-\emph{interval}
level $\eta/(2|\Dcal|\cdot 6)=\eta/48$, which places $\eta/96$ in each tail, every one of the
twelve directions remains strictly positive,
binding at Haiku's $L_{\Dcal}(W_1,W_2)=+0.146$ and reaching $+0.684$ on the stark cells.
The claim ``all six models are empirically incomparable'' therefore holds \emph{simultaneously} at
$\ge 90\%$, not merely model by model. Table~\ref{tab:consolidated} reports the per-model bounds;
the simultaneous ones are uniformly smaller by $0.077$ to $0.084$ and change no verdict.

Because incomparability is a two-directional claim, both $L_{\Dcal}$ bounds must be positive; the
smaller of the two is the binding one. Two cells carry each model's verification, and which two
is model-specific: on five models they are one API cell and the encoding cell, while on
DeepSeek-V4-Pro the $W_1$-over-$W_2$ direction is carried by the \emph{trap} cell rather than an
API cell (its API margins being smaller). The effective support of the surrogate is therefore two
cells per model, drawn from a battery of four. We therefore describe
$\Dcal$ as a fixed adversarial four-cell battery rather than a sampled task distribution: the
verification is valid for what it covers, and what it covers is a single hand-built API-versus-encoding
opposition run against six models---six rules on one pair, with $W_1$, $W_2$ and $\Dcal$ held fixed
and only $\delta_M$ varying, not six independent source-pair replications. The $n$ draws behind a
cell are repeated outputs on \emph{one} task, which is what the Bernoulli model of
Assumption~\ref{ass:iid} prices; no interval in this paper samples tasks.

\subsubsection{The relevance score mis-ranks the sources}
\label{sec:results-misrank}


On the trap, query-conditioned lexical relevance ranks $\varphi_{\mathrm{lex}}(W_1) = 0.36 <
\varphi_{\mathrm{lex}}(W_2) = 0.44$, so it prefers $W_2$; yet realized PASS ranks $W_1 \gg W_2$ on all
six models (Haiku $95\%$ vs.\ $0\%$; Sonnet, Opus, GPT-5.5, and Kimi $100\%$ vs.\ $0\%$;
DeepSeek $98\%$ vs.\ $0\%$). On the two non-trap cells relevance \emph{agrees}
with PASS, on the API cells relevance ranks $W_1 > W_2$ and so does PASS, and on the encoding cell
relevance ranks $W_2 > W_1$ and so does PASS, so the score fails \emph{only} where utility diverges
from topicality, exactly the regime Theorem~\ref{thm:incomparable} and
Proposition~\ref{prop:trap-constrained} isolate. The \texttt{none} floor on the trap is $0\%$ on
all six models, and $W_2$ scores $0\%$ there too, confirming both that the convention is
unguessable and that encoding knowledge is useless on this task.

The ranker spectrum is the point here: dense retrievers and a cross-encoder fall for the trap
while a listwise reranker escapes it. To test whether the mis-rank extends beyond bag-of-words,
we scored $\{W_1,W_2\}$ against the
probe tasks with representative open-weight rankers, two dense bi-encoders
(\texttt{bge-small-en-v1.5}, \texttt{e5-small-v2}) and a cross-encoder reranker
(\texttt{ms-marco-MiniLM-L-6-v2}), and with a RankGPT-style LLM \emph{listwise} reranker (Haiku
one turn, seeing the task and \emph{both} sources; both presentation orders; $n=100$ judgments
per task). Table~\ref{tab:rankers} reports the induced rankings. Every feature-based
ranker we tested mis-ranks the trap: both dense bi-encoders prefer $W_2$ on the trap while
ranking both non-trap cells correctly, textbook topical behaviour, and the cross-encoder prefers
$W_2$ on the trap with maximal confidence (logits $-5.63$ for $W_1$ vs $+3.24$ for $W_2$) while
being near-tied (and narrowly wrong) on the encoding cell. The LLM listwise reranker,
which can read the verifier-decisive coordinate rather than match surface features, tracks
realized PASS everywhere, unanimously: $100/100$ per task, split evenly across the two
presentation orders so that a ranker merely preferring the first document would show. Unanimity
at $n=100$ puts the exact $95\%$ Clopper--Pearson lower bound on the preference rate at $0.964$;
at the pre-declared halfway checkpoint of $50$ judgments it was $0.929$, and $10$ judgments would
have bounded it only at $0.692$, too close to chance for a claim about consistent ranking. This sits on the boundary
Proposition~\ref{prop:trap-constrained} draws: its hypothesis is \emph{topicality}, invariance to
the decisive coordinate, and the trap defeats the lexical, dense and cross-encoder checkpoints we
ran while sparing the one ranker that reads content. Two limits on how far this generalizes. The
three families are three checkpoints on one trap, so their failure is measured, not proved for the
families at large; and the proposition does not establish that a model call per candidate is
\emph{necessary} to escape, since a router reading public task metadata would also escape at no
such cost (Remark~\ref{rem:trapscope}). What the measurement does show is that the scorers
actually deployed here, which read text, pay that price.

\subsubsection{Anti-monotonicity: a verified superset that hurts}
\label{sec:results-antimono}


The superset $W_{1+}$, which literally \emph{contains} $W_1$'s signal, sharply degrades the API
cells relative to $W_1$ alone. The per-task harm contrast
$\Delta_T = \PASS(W_{1+},T) - \PASS(W_1,T)$ is verified negative ($\Delta_T \le -\tau$,
$\tau=0.30$) on all twelve API cells, two per model, and so on every one of the
six models (Table~\ref{tab:interference}, Figure~\ref{fig:forest}). Those twelve are \emph{marginal}
verifications, each at $\ge 1-\eta$ for its own cell; the conjunction can be bought from the same
records, since spreading $\eta$ across all twelve contrasts, a per-interval level of $\eta/12$ over
the $24$ endpoints, still leaves eleven clear of $-\tau$ with every model keeping at least one. The
roster-level statement ``on each of these six models some strict superset verifiably harms some
cell'' therefore holds \emph{simultaneously} at $\ge 90\%$, not merely model by model. The mildest
verified collapse is DeepSeek's \texttt{api\_argorder}, $68\% \to 5\%$ at upper bound $-0.38$, the
one cell the joint budget drops; all twelve also survive a Bonferroni correction across the two
cells within each model. Haiku's shallowest collapse is on \texttt{api\_argorder}, $80\%\to0\%$,
shallow only because its $W_1$ arm is not at ceiling. This is a verified empirical
falsification of superset-\emph{monotonicity} for these fixed rules (Theorem~\ref{thm:antimono}):
strictly-more-informative context can hurt, and the deficiency framework detects it precisely where
every monotone scalar must miss it. Table~\ref{tab:percell} gives the same collapse arm by arm for
every model.

The idealized Blackwell order on $\mathcal{C}=\{W_1,W_2,W_{1+}\}$ collapses the choice to the
superset: $W_{1+}$ reveals both coordinates, so $W_{1+}\Bord W_1$ and $W_{1+}\Bord W_2$, and
``more signal is better'' keeps $\{W_{1+}\}$ alone. The verified empirical relation for the fixed
rule has the opposite shape (Figure~\ref{fig:hasse}): $W_1$ beats $W_{1+}$ on the API cells,
$W_{1+}$ beats $W_1$ on the encoding cell, and $W_1$ and $W_2$ are the verified incomparable pair,
so the \emph{point estimate} of the $\PASS_M$-non-dominated front is the two-element set
$\{W_1, W_{1+}\}$, an object no scalar top-$1$ rule can represent; the two-sided
inclusion below bounds it. Three sources over four cells need
\emph{one} coverage event, so all
$3\times 4$ Clopper--Pearson intervals are taken at per-interval level $\eta/12$; they hold jointly
at $\ge 1-\eta$ and every relation in the figure is read off that single event. On the $n{=}40$
Haiku record $L_{\Dcal}(W_1,W_2)=+0.2070$ and $L_{\Dcal}(W_2,W_1)=+0.7439$, both positive,
which verifies the incomparable pair.
Non-dominance is likewise a \emph{lower}-bound statement, and the same event supplies it:
$L_{\Dcal}(W_{1+},W_1)=+0.7439$, witnessed by \texttt{api\_post\_ok}, shows that $W_1$ beats
$W_{1+}$ on some cell, and $L_{\Dcal}(W_1,W_{1+})=+0.7439$ shows the converse, so neither dominates
the other. An upper bound could carry neither claim: it bounds how large an advantage \emph{might}
be, not that one exists. The relation the front turns on has only an upper bound,
$U_{\Dcal}(W_{1+},W_2)=0.1281$. That is an $\varepsilon$-dominance rather than an exact one, saying
that on \emph{every} cell of the battery $W_2$ can beat $W_{1+}$ by at most $0.1281$, so excluding
$W_2$ is licensed only up to that margin. What the coverage event establishes exactly is the
two-sided inclusion
\[
  \{W_1, W_{1+}\} \;\subseteq\; F \;\subseteq\; \{W_1, W_{1+}, W_2\},
\]
where $F$ is the $\PASS_M$-non-dominated front on $\mathcal{C}$: both $W_1$ and $W_{1+}$ are
verifiably in it, and at $n=40$ a three-element front cannot be ruled out. The selection rule the
figure implies, keep the non-dominated set rather than force the superset, holds under either
reading.

\paragraph{What the position controls show.}
On Haiku, the collapse persists under reversal of the two source blocks, and character-matched
off-topic padding does not reproduce it. The padding control (Appendix~\ref{app:record}) fills
the slot $W_2$ occupies inside $W_{1+}$, $W_1$ last in both, and leaves the padded arm at ceiling
on \texttt{api\_argorder} ($40/40$, against $W_1$ alone's $31/40$): changing only that slot's
content turns a harmless arm harmful. The
reversed arm $W_{1+}^{\mathrm{rev}} = W_1 \,{+}{+}\, W_2$ puts $W_1$ first, over the same
transport and $n=40$ as the main table (\texttt{blackwell\_controls\_api\_n40}). The two
orderings are indistinguishable on both cells: $W_{1+}$ and $W_{1+}^{\mathrm{rev}}$ each take
$W_1$ from $39/40$ to $0/40$ on \texttt{api\_post\_ok} and from $31/40$ to $0/40$ on
\texttt{api\_argorder}, verified harmful at $-0.81$ and $-0.56$ respectively. Moving the added
block out of the primacy slot therefore changes neither the sign nor the size of the harm, which
constrains a positional account of the collapse without ruling one out for configurations we did
not test. On one model and in this configuration, the controls constrain positional and
gross-length explanations without identifying a unique cause or isolating tokenization,
processing difficulty, or the internal mechanism; the reversed arm bounds the \emph{existence}
of a positional explanation, not position's contribution to the harm's size.

\paragraph{Robust across the capability ladder.}
The harm is large and robust across the Anthropic capability ladder. On the two API cells the
$W_1 \to W_{1+}$ collapse is Haiku $100\%/80\% \to 0\%/0\%$, Sonnet $100\% \to 0\%/0\%$, and Opus
$100\% \to 0\%/0\%$ (Table~\ref{tab:interference}). Both stronger models sit at the floor on both
cells, so this record orders neither for nor against a capability trend: an earlier two-point
reading suggested the harm ``intensifies with strength'', and we now claim only robustness
across the ladder, not a capability trend. All three Anthropic models collapse to $0\%$ on both
cells, so there is no residual spread to order. What survives is the negative claim, not the
ranking that motivated it.

\subsubsection{The model-relative value of private context}
\label{sec:results-moat}


The ``private'' conventions are genuinely unguessable for some vendors and partially known to others,
and this varies continuously. The \texttt{none}-arm baseline on \texttt{api\_argorder} forms a clean
spectrum: Sonnet and Haiku $0\%$, DeepSeek $2\%$, Kimi $45\%$, GPT-5.5 $75\%$. Opus is
excluded from this comparison: it solves \texttt{api\_argorder} unaided in $40/40$ draws, so
for that model the cell measures no value of private context at all
(Table~\ref{tab:consolidated}). So the value of the private context, the
model-relative guessability $\PASS_M(\texttt{none},T)$ of Section~\ref{subsec:theta}, varies continuously across
models, and it is not ordered by capability. What it does track we cannot identify from these
runs. DeepSeek, a different vendor,
has a tight prior like the smaller Claude models, while GPT-5.5's prior already holds much of the
convention (\texttt{api\_argorder} $75\%$, \texttt{enc\_amount} $55\%$), so a
``stronger-model-knows-more'' account does not fit. Utility-centric retrieval reaches the same
conclusion from the other side, the same passage carrying different utility for different
models~\citep{zhang2025llmutility}; what the spectrum adds is the verified per-model floor. Within
Anthropic, no-context PASS on \texttt{api\_argorder} runs from $0/40$ for Haiku and Sonnet to
$40/40$ for Opus. These observations do not identify how guessability relates to general model
capability or to training data; no independent capability scale is measured here. The verified per-model claims rest on cells unguessable \emph{for the model under test}
(e.g.\ GPT-5.5 \texttt{api\_post\_ok} \texttt{none} $= 5\%$, trap $= 0\%$).

\subsubsection{What the failing replies contain}
\label{sec:results-audit}


Raw completions were retained for the three Anthropic models' rows of the interference table,
$40$ per arm and cell; the other three models' rows are aggregate-only, so what follows is read
off half the table (Appendix~\ref{app:diag}). Three text screens bear on the collapse, over the
$480$ replies of the $W_1$ and $W_{1+}$ arms there. The empty-extraction and explicit-refusal
screens return no matches at all. The import screen detects one omission among the $240$ superset
replies and seven among the $240$ $W_1$ replies, the latter concentrated in the arm that passes,
so those omissions cannot explain the superset arm's collapse. Each screen bears only on what it
tests---an empty extraction, a missing import, refusal language---rather than on every packaging
or declining behaviour, and none was run on the three models whose draws were not retained. \emph{The harmful arm is verbose}: on Haiku the mean reply runs $105$
characters against $477$ on \texttt{api\_post\_ok} and $459$ against $633$ on
\texttt{api\_argorder}, the same inflation reported in Section~\ref{sec:disc-mechanism}.

What the retained text does \emph{not} establish is the mechanism. A textual flag for $W_2$'s wire
encoding appearing in the reply, stated as a rule in Appendix~\ref{app:audit}, fires on $240/240$
of the superset replies across the three models and both collapse cells and on $0/240$ of the
$W_1$ replies. It also fires on $238/240$ of the $W_2$ replies in those cells, every one of which
fails the API verifier, so it is not a test of correctness. These counts describe an output
pattern associated with the source condition; they do not identify an internal cause.
Theorem~\ref{thm:antimono} constrains any rule whose PASS falls under a strict superset, whatever
that cause turns out to be.
\subsection{Generality and controls (summary)}
\label{sec:results-generality}

Four follow-up experiments address three threat axes (source-pair generality, the context-length
confound, and prompt-curability of the collapse); full protocols and numbers are
in Appendix~\ref{app:record}. \textbf{(i) A second incomparable pair, different domain}: a private
\texttt{cache}-module contract versus a key-normalization invariant is again verified incomparable
on Haiku at $n=40$ ($L_{\Dcal} = +0.728/+0.586$), over the same transport as the six-model
record. The superset also collapses the contract cell, $35/40$ to $0/40$, at an upper bound of
$-0.62$ once the budget is spread over the pair's three contrasts, so the second domain carries a
verified collapse of its own; on the trap cell the effect is mild and unverified, $29/40$ to $26/40$
(Section~\ref{sec:limitations}). \textbf{(ii) Length-matched
padding}: an equally long filler arm stays at ceiling on both collapse cells ($40/40$, against
$W_{1+}$'s $0/40$ and $W_1$ alone's $39/40$ and $31/40$), which constrains the gross-length
explanation on this model.
\textbf{(iii) Routing instruction}: a one-line convention-routing note recovers most of the
collapse ($0\%\to82\%$ and $0\%\to98\%$); writing that note requires knowing which source is
decisive for which task family, which is exactly the coordinate structure the partial order
formalizes, so the cure presupposes the diagnosis. \textbf{(iv) Structured context}: wrapping the
same two conventions in labeled XML sections \emph{without} any routing statement does not
mitigate at all ($0\%$ on both cells, against $82\%$ and $98\%$ with the routing note), so
segmentation alone does not cure the interference and the operative variable is routing
knowledge. What the four arms show is a two-way contrast rather than a graded hierarchy:
segmentation recovers nothing at all, while routing recovers most of the collapse and, on
\texttt{api\_argorder}, matches or exceeds what $W_1$ alone achieves in this control ($39/40$
against $31/40$; the one-sided $90\%$ lower bound is $+0.0095$, while a two-sided $90\%$ interval
contains zero). Read as a mechanism this points at convention-to-task
routing rather than convention segmentation, but it is one model at $n=40$ and the reading is an
interpretation of the contrasts, not a verified claim.

Three structural facts, not the magnitudes, are the point. First, the two scalar policies fail on

(Theorem~\ref{thm:incomparable}, Proposition~\ref{prop:trap-constrained}). Second, the policy that
refuses to choose is the \emph{worst} of the four: anti-monotonicity is the dominant cost
(see Section~\ref{sec:results-antimono}). Third, the oracle shortfall from $100\%$ is neither pure selection
error nor pure capability. For DeepSeek ($68$--$75\%$ band) it is residual failure under the
prompts and decoder we tested, which is not a bound on what the model can do. For Haiku the
largest remaining shortfall is on \texttt{enc\_amount} ($22/40$), and on \texttt{api\_argorder}

packaging effect rather than a selection error. The four cells were built to exhibit the phenomenon, so
these magnitudes diagnose the failure structure rather than estimate production-traffic gains.

\paragraph{What follows for practice.} Four statements survive the caveats above.
(i) One number per source is structurally lossy: when two sources each carry a decisive fact, any
single task-independent ranking drops one of them (Theorem~\ref{thm:incomparable}). Keep both and
route by task instead; the per-cell maximum in Table~\ref{tab:policies} is headroom read off
the test outcomes, and no implementable router here captures it, on these tasks or new
ones. Concatenating them is not forbidden
by the theorem, but on this pair it is the worst of the four policies measured
(Table~\ref{tab:policies}).
(ii) Do not cache a source's \emph{value} across task families; cache retrieval representations
instead, because the value is model- and task-relative (see Section~\ref{sec:results-moat}).
(iii) Adding correct, on-topic text to a working prompt can break it, by as much as
$100\%\to0\%$, so a regression after enlarging the context is a candidate anti-monotonicity
collapse before it is a model failure (see Section~\ref{sec:results-antimono}).
(iv) A cheap topical ranker fails exactly where the surface lexicon points at the wrong source,
which is where a listwise reader earns its cost (Proposition~\ref{prop:trap-constrained}).
Each is measurable on any stack with the released harness.
\section{Discussion}
\label{sec:discussion}
% ==========================================================================

The results recast a piece of practitioner folklore, ``relevance does not transfer across tasks'',
as a structural fact: when two sources are Blackwell-incomparable the order over them is partial,
and any per-source scalar score, by imposing one task-independent preorder, must fail to rank them
faithfully on some task. What follows
concerns what that evidence does and does not license, and where the formalization is a model of
the realized object rather than a proof about it.

\subsection{Scope of the claims}
\label{sec:disc-bridge}\label{sec:disc-deficiency}\label{sec:disc-certificate}

Three limits of scope govern everything above. \textbf{(i) Two registers.} The theorems are about
the ideal user of a source; every number we measure is the pass rate of one fixed, non-optimal
rule $\delta_M$. The two registers are established separately, not one from the other. Structural
incomparability follows from the projection construction and Lemma~\ref{lem:noref}, with no prior,
no caps and no measurement. The experiments separately verify realized cross-advantage for the
fixed model on the named task pairs (Assumption~\ref{ass:attain}), which is
$(M,\Dcal)$-incomparability and nothing more. Lemma~\ref{lem:bridge} is a conditional
Bayes-value criterion whose guessing-cap hypotheses these state-conditional measurements do not
estimate. So the measured crossover does not \emph{earn} the structural conclusion, and need
not: for these sources Lemma~\ref{lem:noref} already supplies it by construction. \textbf{(ii) The estimator's name.} $\dhat_{\Dcal}$ does no minimization
over garblings and ranges over a fixed set of tasks; it is a one-sided \emph{value-deficiency
surrogate}, not a Le~Cam deficiency, and the two are not interchangeable for a fixed rule
(Remark~\ref{rem:notlecam}). What is rigorous is the verification, which we regard as the most
robust part and which stands whether or not the deficiency analogy holds. \textbf{(iii) What the
verification covers.} It is correct because it pays for picking the worst task with exact intervals
and a union bound; its support is small (two of the four cells carry each model's result, and
which two is model-specific: an API cell and the encoding cell on five models, the trap cell
rather than an API cell on DeepSeek-V4-Pro), each family is controlled simultaneously at level
$\eta$ over the intervals it names, while the conjunction \emph{across} families carries no single
joint guarantee (see Section~\ref{subsec:fwer}), and we call $\Dcal$ a fixed adversarial battery,
not a task distribution.

\subsection{Anti-monotonicity is real, verified, but not capability-ordered}
\label{sec:disc-antimono}

The harm object is the direct contrast $\Delta_T = \PASS(W_{1+},T) - \PASS(W_1,T)$, which measures
whether appending the (irrelevant-to-this-task) $W_2$ to a sufficient $W_1$ degrades performance
(the second difference $\Psi_T$ is an interaction term, not a harm measure;
Remark~\ref{rem:psinotharm}). We verify $\Delta_T \le -0.30$ on at least one cell for all six
models (Table~\ref{tab:interference}); nine of the twelve cells are a stark $40/40 \to 0/40$
(upper bound $-0.85$), on both API cells of Sonnet, Opus, GPT-5.5 and Kimi and on Haiku's
\texttt{api\_post\_ok}. This is a verified empirical falsification of
superset-\emph{monotonicity} for these fixed rules (Theorem~\ref{thm:antimono}): a literal
superset of a sufficient signal can
sharply reduce PASS, which no monotone scalar context-value score can represent.

Three cautions attach to it. The harm is robust across the capability ladder but not ordered by it
(see Section~\ref{sec:results-antimono}), so we claim no capability trend. Which cell carries the
verification is still a choice: we fix it per model before unblinding rather than picking the
starkest afterwards, and cells differ in their $W_1$ ceiling, so magnitudes are not comparable
across models even though each binary verdict stands on its own. And the two Opus rows join arms
from different collection windows (see Section~\ref{sec:methodology}); the harm contrasts do not,
since each is read within a single run.

\subsection{Mechanism: a correlate, not an explanation}
\label{sec:disc-mechanism}

On both collapse cells of all six models the harmful arm inflates output, between $+54\%$ and
$+321\%$ (see Appendix~\ref{app:diag}). On the still-passing encoding cell the same
superset arm ranges from $-73\%$ to $+41\%$ with no consistent direction, so the association does
not establish an internal cause and we treat it as a reproducible correlate of the harmful arm
rather than a
mechanism. Per-model figures are in Appendix~\ref{app:diag}.
\subsection{Limitations and threats to validity}
\label{sec:limitations}

We collect the scope restrictions here; each is stated once and sized to its weight.

\paragraph{From diagnosis to selection.} The constructive selection rule the partial order
implies, keep the verified non-dominated set and cover what it leaves uncovered, is left for
future work; here we note only its cost. Building the verified order on $m$ candidates costs
$m\!\cdot\!|\Dcal|\!\cdot\!n$ verifier-gated calls, curation scale, not corpus scale; scaling
verified selection to retrieval over $10^6$ passages, by amortizing the probe into a learned
deficiency predictor or running the partial-order step as a re-ranking head over a scalar
shortlist, is the central open problem this work opens. Keeping a non-dominated set instead of a
top-$k$ prefix already exists as an operator, the skyline retrieval step of \citet{skylinerag2026}, and learned
set selectors optimize evidence sets end to end~\citep{optiset2026,rank4gen2026}; what the partial
order adds is the object the set is taken over, verified task value rather than heuristic per-item
scores. We do not claim that retaining the non-dominated set makes downstream selection
\emph{safe} under anti-monotonicity, and nothing here proves it: the verification bounds the
relation \emph{between} the candidates, not what a selector then does with them, and
concatenating two retained members is the move our own record shows can lower PASS
(see Section~\ref{sec:results-antimono}). What the partial order contributes at this level is
diagnostic.

\paragraph{Source-pair generality.} Incomparability and dominance hold for two hand-built pairs
in two domains, both measured over the same transport as the six-model record. On the second
pair the verification returns $L_{\Dcal}=+0.728/+0.586$, so the crossover is present in a
\texttt{cache} module as well as a \texttt{ledger} one, and the superset carries a verified
collapse there too: it takes the contract cell from $35/40$ to $0/40$, upper bound $-0.62$ with
the budget spread over the pair's three contrasts. The other two cells do not collapse; the trap
cell moves only $29/40$ to $26/40$, nowhere near the $\tau=0.30$ margin. An earlier command-line
measurement of this pair behaved differently enough that we reported it as regime-dependent; that
caveat concerned a transport the record no longer uses. Two gaps remain. The cross-vendor record
is still single-pair: five of the six models were never run on it. And the pair did not reproduce
the relevance-trap effect at all, its prompt not being lexically $V_2$-leaning, so the strong
mis-rank is still a one-pair result. A third
domain and a vendor-general strong mis-rank remain open next steps.

\paragraph{Cross-vendor magnitudes are still only suggestive.} All six models are now run the same
way, one HTTP request per draw at $n=40$ (see Section~\ref{sec:methodology}), so neither the turn
budget nor the transport confounds the comparison. What remains is the
ordinary caution that different vendors' models differ in ways we do not control (training data,
size, tokenizer), so the \emph{magnitude} comparisons (the value spectrum, the $\Delta_T$ ladder)
should be read as suggestive; the binary within-model claims do not depend on any cross-vendor
comparison.

\paragraph{The construction is an idealization.} It models sources as clean projections onto
independent coordinates; real chunks overlap, contradict, and leak (the measured
$\theta$-dependence is exactly such leakage), so it is the cleanest \emph{sufficient} condition
for incomparability, realized exactly by our hand-built pairs and not claimed of arbitrary ones.

\paragraph{Prevalence is not measured, and is the decisive next experiment.} Every claim here is
existential: it establishes \emph{that} verified incomparability and superset harm occur, on which
models, and with which confounds excluded. It does not establish \emph{how often} either occurs in
a deployed retrieval stream, and no number in this paper should be read as an estimate of that.
The four cells were built to make the structure visible, so their aggregate magnitudes are
diagnostic of the failure mode rather than of production traffic. The direct experiment is
specified: draw document pairs from a natural corpus, keep the procedure of
Section~\ref{sec:estimator} but write tasks and verifiers that corpus admits, since the four
ledger and wire tests do not transfer, and report what fraction verifies incomparable and
harmful, with the sampling frame stated. That fraction converts into a lower bound on prevalence
without a union bound over pairs. Write $\pi$ for the probability that a drawn pair has the
property and $V$ for the event that the procedure verifies it. The procedure is one-sided at level
$\eta$, so $\Pr[V \mid \text{not } I] \le \eta$ and therefore $\Pr[V] \le \pi + (1-\pi)\eta$,
which rearranges to $\pi \ge (\Pr[V]-\eta)/(1-\eta)$. Replacing $\Pr[V]$ by an exact
Clopper--Pearson lower bound $\underline{p}$ on the verified fraction over the sampled pairs gives
$\pi \ge \max\{0,\,(\underline{p}-\eta)/(1-\eta)\}$ at confidence $1-\alpha$: the correction
applies to one marginal probability, not once per pair, because nothing here asserts that each
individual verified pair is a true positive. Three conditions bind. The pairs and the procedure's
outcomes must be i.i.d.\ draws from the stated frame; adaptive selection breaks that, and
sharing documents across pairs may introduce dependence. The property $I$ is whatever the certificate actually
verifies---PASS-incomparability for a named model on a named task battery, not unconditional
Blackwell incomparability of the underlying sources. And a joint claim, ``incomparable
\emph{and} harmful,'' needs $I$, $V$ and the one-sided error $\eta$ redefined for that conjunction
rather than reusing these. We name prevalence as the open question rather than approximate it
here, because a figure computed from hand-built pairs would be circular.

\paragraph{Scope of the behavioural controls.} The padding, routing-note and structured-context
arms, and the reversed-order arm, were each run over the same API path as the main record, on
Haiku at $n=40$ on the two collapse
cells, in the same regime and on the same task versions as the main table. None of the four is part of the six-model
record, so what these controls establish is established on one model, not across the roster. The
padding match is by \emph{characters} ($1108$ against $1095$ at the arm level), not by subword
tokens, and because $W_2$ is symbol-dense while the filler is plain prose the two arms are not
tokenizer-matched; token count is therefore \emph{not} isolated, only gross length. The filler is
also off-topic for the \texttt{ledger} module. Taken together, on this model the added block's
content and the routing instruction move the outcome, while equal character-length off-topic
filler does not. The controls constrain positional and gross-length explanations in the tested
configuration rather than eliminating them: they do not isolate tokenization or processing
difficulty, do not identify a unique cause, and do not exclude every position-dependent
mechanism. Reversing the two blocks leaves both cells at $0/40$, so on this record order changes
neither the sign nor the size of the harm, which constrains a positional account without ruling
one out for configurations we did not test. The mechanism and
refusal counts of Appendix~\ref{app:diag}, with the non-empty extraction record, are likewise
automated flags over retained draws: they document what the failing replies contain, establish
no universal causal mechanism, and do not exclude every packaging problem. A
tokenizer-matched control and an on-topic but verifier-irrelevant control remain untested, as
does any of these across the roster. The order control has been run over the same API path as the
rest of the controls, but on one model and on the two collapse cells only
(see Section~\ref{sec:results-antimono}).

\paragraph{Sampling and verification regime.} The verification assumes $n$ i.i.d.\ Bernoulli PASS
draws per cell (Assumption~\ref{ass:iid}). Each draw is a separate call with no shared session or
conversation history (protocol in Appendix~\ref{app:repro}), which makes independence plausible;
it does not \emph{establish} it, nor that the served backend was stationary across a run. Both
remain assumptions on which the coverage statements depend, and a provider-side model or routing
change during a run would break them silently. Stationarity \emph{between} runs rests on less
still, and the cross-window contrasts of Section~\ref{sec:methodology} depend on it; the
within-run harm contrasts do not.
Marginal-versus-joint control is discussed in Section~\ref{sec:disc-bridge}.

\paragraph{Ranker spectrum and synergy.} The trap mis-rank spans lexical cosine and three
representative open-weight learned rankers, with an LLM listwise reranker ranking the pair
correctly, which the theory permits rather than predicts, but the
learned checkpoints are the small members of their families and the evidence is one trap in one
domain. The mis-rank is not evidence of class membership: we do not verify that any learned
checkpoint's score is invariant to the verifier-decisive coordinate or increasing in lexical
overlap alone, so Proposition~\ref{prop:trap-constrained} is not shown to bind these
rankers. Positive
interference (synergy) is untested by construction: $W_1, W_2$ are
task-disjoint, so a complementary pair would be needed to test whether a superset can also
\emph{help} beyond its parts; we make no claim about it.

\section{Conclusion}
\label{sec:conclusion}
% ==========================================================================

Context selection is a partial-order problem, not a scalar one. Blackwell's comparison of
experiments identifies a structural limitation of task-independent context rankings: when two
sources are incomparable, no one per-source score fixed across tasks ranks them correctly for every
decision problem (Theorem~\ref{thm:incomparable}). For \emph{fixed} model rules we measure a
separate, task-restricted PASS relation with finite-sample bounds, tied to the classical order only
through the conditional bridge of Lemma~\ref{lem:bridge}. On six models across four vendors both
directions of PASS-incomparability stay positive under a joint $90\%$ guarantee; on each of them a
deployed relevance score ranks the pair the wrong way on a designed trap; and adding a strictly
larger source lowers PASS on all twelve tested API contrasts, eleven of which meet the $0.30$ harm
margin under joint $90\%$ control, with every model retaining at least one verified contrast. What a private source is worth is model-relative: guessability runs from
$0\%$ to $100\%$ across the six models, one of which solves the task with no context at all, and
what it tracks these runs cannot identify. Bringing Blackwell and Le~Cam to inference-time context is not ours to claim; concurrent
work reached the same apparatus from the admission side (see Section~\ref{sec:related-deficiency}). What
follows from taking \emph{incomparability} rather than deficiency-minimization as the object is the
impossibility, and the instrument that tests it.

The scope is narrow and stated exactly. Theorem~\ref{thm:incomparable} and
Lemma~\ref{lem:bridge} concern the idealized Bayes-optimal user, while
Theorem~\ref{thm:antimono} concerns the fixed rule a model realizes and invokes no such user at
all; the measured crossover and collapse are properties of those \emph{fixed} rules; the two
sources'
incomparability is structural, resting on the projection construction and Lemma~\ref{lem:noref}
rather than on measurement; Lemma~\ref{lem:bridge} is a conditional Bayes-value criterion whose
guessing caps we do not estimate; and the estimator is a regret-gap surrogate, not a Le~Cam
deficiency. All six models are measured under one protocol, so cross-vendor magnitudes carry no
transport confound; they remain read with caution as model differences and collection windows
(see Section~\ref{sec:methodology}); the verified claims are within-model contrasts. What the impossibility
excludes is one number per source fixed across tasks and query-conditioned scores meeting the two
hypotheses of Proposition~\ref{prop:trap-constrained}; a task-conditioned score, a router over
public metadata, or a listwise reader that pays to read the decisive content lie outside it
(Remark~\ref{rem:trapscope}). The behavioural controls constrain block-order and gross-length
explanations on one model; they do not establish an internal mechanism. The decisive next test is
prevalence: draw source pairs from a
natural corpus rather than building them, run the same verification unchanged, and report how often
a deployed retrieval stream produces a pair that verifies incomparable (see Section~\ref{sec:limitations}).

\subsection*{Proof of Lemma~\ref{lem:noref}}
\begin{proof}
\emph{(a)} For deterministic experiments a garbling $G$ with $\kappa_{W_B}=G\circ\kappa_{W_A}$
must compute $\pi_B(S)$ from $\pi_A(S)$ alone (no further access to $S$). Such a measurable map
exists iff $\pi_B$ is $\sigma(\pi_A)$-measurable, i.e.\ $\Fcal_{W_B}\subseteq\Fcal_{W_A}$.
Under coordinate independence and non-degeneracy, $\sigma(\pi_B)\subseteq\sigma(\pi_A)$ holds iff
every coordinate in $B$ is among those in $A$, i.e.\ $B\subseteq A$: if some $j\in B\setminus A$,
then $S_j$ is independent of $\pi_A(S)$ and non-constant, so it is not
$\sigma(\pi_A)$-measurable, and no garbling can reconstruct it; conversely if $B\subseteq A$ the
coordinate-deletion map is a (deterministic) garbling. \emph{(b)} is the contrapositive of (a)
applied in both directions.
\end{proof}

\subsection*{Proof of Lemma~\ref{lem:bridge}}
\begin{proof}
\textup{(a)} Suppose, for contradiction, $W_2 \Bord W_1$. By Theorem~\ref{thm:blackwell},
$V^\star(W_2, T) \ge V^\star(W_1, T)$ for every task $T$, in particular at $T_a$. By the
sufficiency hypothesis, $T_a$'s verifier is determined by its decisive coordinate, which lies in
$A_1\setminus A_2$ and is revealed exactly by $W_1$ (Definition~\ref{def:projection}). Solvability,
the hypothesis's separate half, supplies $\mu_{T_a}$-almost surely an action the verifier accepts,
measurable in that coordinate and the facts known $\mu_{T_a}$-almost surely. Reading the coordinate
off $W_1$'s signal and playing that action attains $v_{T_a}=1$ $\mu_{T_a}$-almost surely, so
$V^\star(W_1,T_a)=1$. By hypothesis $g_a = V^\star(W_2,T_a) < 1$, hence
$V^\star(W_1,T_a) > V^\star(W_2,T_a)$, a contradiction. Therefore $W_2 \not\Bord W_1$;
symmetrically $g_b < 1$ forbids $W_1 \Bord W_2$, so $W_1, W_2$ are Blackwell-incomparable.

Two things this argument does \emph{not} use are worth stating, because the natural shorter proof
uses both and is wrong. It never asserts $V^\star(W_1,T_a) \ge \PASS_M(W_1,T_a)$: the left side is
a Bayes value under $\mu_{T_a}$, the right a pass rate at the single realized convention, and
optimality relates $V^\star$ only to the $\mu_{T_a}$-averaged $\overline{\PASS}_M$
(Remark~\ref{rem:measures}). And it never treats the measured crossover as the hypothesis or as an
estimate of it: the caps are assumed, and nothing reported here determines $g_a$ or $g_b$. In the
converse direction the caps keep apart two failures a bare crossover cannot distinguish: opposed
$\PASS_M$ rates on a strictly \emph{comparable} pair, which is what $(W_1, W_{1+})$ gives, with
$W_{1+} \Bord W_1$ strictly and Theorem~\ref{thm:antimono}'s non-coherence a monotonicity
violation; and opposed rates under Blackwell \emph{equivalence}, illustrated without a certified
instance by the padding arm $(W_1, W_{\mathrm{pad}})$ (Remarks~\ref{rem:capsrole}
and~\ref{rem:partial}). Neither licenses a structural conclusion from a crossover alone.

\textup{(b)} Assumption~\ref{ass:attain} directly yields $\PASS_M(W_1,T_a) > \PASS_M(W_2,T_a)$
and the reverse at $T_b$, which is Definition~\ref{def:dmorder}'s incomparability. The
unconditional converse fails, witnessed by the decoder that ignores its context: whatever the
sources, $\PASS_M(W_1,T) = \PASS_M(W_2,T)$ for every $T \in \Dcal$, so $W_1 \succeq_{M,\Dcal} W_2$
and $W_2 \succeq_{M,\Dcal} W_1$ both hold and the pair is $(M,\Dcal)$-comparable however
Blackwell-incomparable it is. A monotonicity violation on a \emph{comparable} pair is a different
phenomenon, not by itself such a witness.
\end{proof}

\subsection*{Proof of Theorem~\ref{thm:incomparable}}
\begin{proof}
By incomparability, neither source garbles the other. By the contrapositive of
Theorem~\ref{thm:blackwell}, ``not $W_1 \Bord W_2$'' yields a task $T_b$ (a prior plus bounded
utility) with $V^\star(W_2,T_b) > V^\star(W_1,T_b)$, and ``not $W_2 \Bord W_1$'' yields a task
$T_a$ with $V^\star(W_1,T_a) > V^\star(W_2,T_a)$; both inequalities are \emph{strict}. These witnesses carry bounded utility and need not be binary
verifiers (Definition~\ref{def:decision}); for projection sources they may be taken binary (proof
of Lemma~\ref{lem:bridge}\textup{(a)}). A query-independent $\varphi$ assigns the single ordered
pair $(\varphi(W_1), \varphi(W_2))$, fixing one task-independent total \emph{preorder} on
$\{W_1,W_2\}$. If $\varphi(W_1)=\varphi(W_2)$ it expresses no strict preference and is unfaithful
on both; otherwise the strict order it fixes agrees with the optimal-value order on at most one of
$T_a, T_b$ (they point opposite ways) and is violated on the other. Either way faithfulness fails
on at least one, which is the claim, and a fixed task-independent tie-breaking rule only removes
the first case. The $\PASS_M$ conclusion follows by replacing $V^\star$ with
$\PASS_M$ via Assumption~\ref{ass:attain}, which guarantees the realized rule reproduces both
strict inequalities with margin $\gamma$.
\end{proof}

\subsection*{Proof of Proposition~\ref{prop:trap-constrained}}
\begin{proof}
For (a), $\varphi=g\circ\psi$ and $\psi(W_1,T_c)=\psi(W_2,T_c)$ force equal scores, while
faithfulness on $T_c$ would require a strict gap. For (b), $\mathrm{ov}(W_2,T_c) >
\mathrm{ov}(W_1,T_c)$ with $g$ strictly increasing gives $\varphi(W_2,T_c) > \varphi(W_1,T_c)$,
while utility favours $W_1$ because $T_c$'s PASS requires $W_1$'s coordinate; the two orders
disagree. Part (b) makes
explicit the two things the informal reading of ``saturated lexicon'' presumes, strict monotonicity
and overlap being the only feature read, without which no strict inequality follows.
\end{proof}
\subsection*{Proof of Proposition~\ref{prop:vinfo-monotone}}
\begin{proof}
Let $G$ be the garbling with $\kappa_{W_2}=G\circ\kappa_{W_1}$. Any predictor $g\in\Vcal$ acting
on $W_2$'s signal is realized on $W_1$'s signal by the composite $g\circ G$, which lies in $\Vcal$
by the closure hypothesis. Therefore the best $\Vcal$-predictor under $W_1$ attains at least the
predictive accuracy of the best under $W_2$, so its expected predictive risk is no larger; the
risk-reduction relative to the common null signal is thus at least as large under $W_1$. The
scalarity is immediate: $I_{\Vcal}$ returns a single real number per source, so it induces one
task-independent total preorder and, by Theorem~\ref{thm:incomparable}, cannot rank a
Blackwell-incomparable pair faithfully on all tasks.
\end{proof}

\subsection*{Proof of Proposition~\ref{prop:certificate}}
\begin{proof}
Let $E$ be the event that all $2|\Dcal|$ Clopper--Pearson intervals contain their true proportions.
Each interval fails with probability at most $\alpha=\eta/(2|\Dcal|)$ (exact coverage of
Clopper--Pearson~\citep{clopperpearson1934}), so by the union bound $\Pr[E^c]\le 2|\Dcal|\cdot\alpha =
\eta$, giving $\Pr[E]\ge 1-\eta$. On $E$, for every $T$ we have $p_{W_2,T}\ge L_{W_2,T}$ and
$p_{W_1,T}\le U_{W_1,T}$, so $p_{W_2,T}-p_{W_1,T} \ge L_{W_2,T}-U_{W_1,T}$; taking $\max_T$ on both
sides, $\sup_T[p_{W_2,T}-p_{W_1,T}] \ge L_{\Dcal}(W_1,W_2)$. Thus on $E$ (probability $\ge 1-\eta$) the
true sup is at least $L_{\Dcal}(W_1,W_2)$, which is the claimed lower confidence bound; if it is positive,
the true sup is positive, verifying $d_{M,\Dcal}(W_1,W_2)>0$. The reverse direction uses
$L_{W_1,T}$ and $U_{W_2,T}$, which are endpoints of the \emph{same} $2|\Dcal|$ intervals already
included in $E$; therefore both one-sided verifications are valid on the single event $E$, and their
conjunction holds at $\ge 1-\eta$ without a further Bonferroni factor.
\end{proof}

\subsection*{Proof of Proposition~\ref{prop:interference}}
\begin{proof}
Only two quantities enter $\overline\Delta_{T^\star}$: an upper endpoint on $p_{W_{1+},T^\star}$
and a lower endpoint on $p_{W_1,T^\star}$. The two arms are independent Bernoulli samples
(separate completions). Let $E_+$ be the event $p_{W_{1+},T^\star}\le U_{W_{1+},T^\star}$ and
$E_-$ the event $p_{W_1,T^\star}\ge L_{W_1,T^\star}$. By the exact one-sided coverage of
Clopper--Pearson at noncoverage $\alpha=\eta/2$ per endpoint, $\Pr[E_+^c]\le\eta/2$ and
$\Pr[E_-^c]\le\eta/2$, so by the union bound $\Pr[E_+\cap E_-]\ge 1-\eta$. On that event
\[
  \Delta_{T^\star} \;=\; p_{W_{1+},T^\star}-p_{W_1,T^\star}
  \;\le\; U_{W_{1+},T^\star}-L_{W_1,T^\star} \;=\; \overline\Delta_{T^\star},
\]
which is the claim; if $\overline\Delta_{T^\star}\le-\tau$ then $\Delta_{T^\star}\le-\tau$ at
confidence $\ge 1-\eta$. Note that the budget is spent on exactly the two endpoints used: a
two-sided interval at level $\eta/2$ would place $\eta/4$ in each tail, leave two endpoints
unused, and deliver $1-\eta/2$ while widening the bound, which is why the allocation is stated
per endpoint rather than per interval. For a post-hoc selected cell, replacing $\alpha$ by
$\eta/(2|\Dcal|)$ and union-bounding over the $2|\Dcal|$ endpoints preserves $\ge 1-\eta$
simultaneous coverage.
\end{proof}

\subsection*{Proof of Theorem~\ref{thm:antimono}}
\begin{proof}
$W_{1+}\Bord W_1$ by deletion of the extra coordinate (a deterministic garbling,
Lemma~\ref{lem:noref}(a)); write $G$ for that deletion, so
$G\circ\kappa_{W_{1+}}(\cdot\mid s)=\kappa_{W_1}(\cdot\mid s)$ for every state $s$. The rule
$\delta_M\circ G$ is then Blackwell-coherent on $T^\star$ in the sense of the theorem, and its
realized pass rate on $W_{1+}$ equals $\PASS_M(W_1,T^\star)$ at the realized state, since the two
rules see the same signal law. The hypothesis
$\PASS_M(W_{1+},T^\star)<\PASS_M(W_1,T^\star)$ therefore says that $\delta_M$ on $W_{1+}$ is
strictly beaten by its own pruned version on the same input, so $\delta_M$ is not
Blackwell-coherent on $T^\star$. Note what this argument does \emph{not} use: it is the
simulation construction behind \textup{(i)}$\Rightarrow$\textup{(ii)} of
Theorem~\ref{thm:blackwell} applied state-conditionally, not an instance of statement
\textup{(ii)}, which is Bayes-averaged and so says nothing about a single state
(Remark~\ref{rem:measures}). A monotone scalar $\phi$ assigns
$\phi(W_{1+})\ge\phi(W_1)$ (monotonicity), hence orders $W_{1+}$ above $W_1$ and cannot reproduce
the realized reversal.
\end{proof}

\subsection*{Relation to LLM-evaluation statistics}
\begin{remark}[Relation to LLM-evaluation statistics]
\label{rem:evalstats}
The verification sits in a small but growing statistical-methodology literature for black-box
model evaluation: paired-difference designs and clustered standard errors for
evals~\citep{miller2024errorbars}, two-sample tests verifying behavioral differences between
API-served models~\citep{gao2024modelequality}, and the recommendation to prefer exact
frequentist intervals over CLT approximations when per-cell $n$ is below a few
hundred~\citep{bowyer2025clt}, which is precisely our regime ($n \in [20,80]$ per cell) and
precisely what the exact Clopper--Pearson construction provides.
\end{remark}

\subsection*{Power and the role of \texorpdfstring{$n$}{n}}
\label{subsec:power}

Both verifications are driven by how close the arms sit to an endpoint. For a stark cell with
empirical proportion at an endpoint ($\hat p\in\{0,1\}$) the Clopper--Pearson interval becomes
one-sided and clears $0$ even at small $n$. It does not become a point: at $n=40$ and two-sided
level $\eta/8$, $0/40$ gives $[0,\,0.119]$ and $40/40$ gives $[0.881,\,1]$, and it is that
$0.119$ the crossing has to beat. The incomparability verification
\eqref{eq:LD} is carried by exactly such cells ($W_1$ at $\approx100\%$, $W_2$ at $0\%$ and vice
versa). The harm contrast \eqref{eq:deltaupper} needs the gap between two arms to exceed $\tau$
after both intervals are paid for, and a negative point estimate need not verify either the sign
of the harm or the margin. On the second source pair's trap cell PASS moves from $29/40$ to
$26/40$, but the one-sided $90\%$ upper bound on the difference is $+0.188345$: neither
$\Delta_T<0$ nor $\Delta_T\le-0.30$ is verified by that contrast.

\subsection*{Generality and controls: full protocols}


Four follow-up experiments address three threat axes: source-pair generality, the context-length
confound, and whether the anti-monotonicity collapse is curable by cheap prompting.

\emph{How the bounds below are to be read.} A bound on a two-arm difference is assembled from the
two proportions' exact intervals. Each endpoint quoted here is a \emph{separate one-sided} $90\%$
bound, which is the form Proposition~\ref{prop:interference} uses and the form in which each harm
claim is made; the two endpoints together carry a guaranteed joint coverage of at least $80\%$
under this union-bound argument, so where a two-sided statement is wanted we assemble it from
individual $95\%$ Clopper--Pearson regions and say so. Decisions use unrounded endpoints;
displayed confidence bounds are rounded outward, lower bounds downward and upper bounds upward.

\paragraph{A second incomparable pair, different domain.}
We repeated the protocol with a second hand-built pair on a private \texttt{cache} module: $V_1$, the
\texttt{cache.put(key, value, *, ttl)} call contract (argument order, required keyword-only
\texttt{ttl}, a True/False ``newly inserted'' flag, a \texttt{CacheError} type), versus $V_2$, a
key-normalization invariant (a fixed \texttt{kx7-} namespace prefix and an underscore rule). On Haiku
at $n=40$ the pair is again verified incomparable ($L_{\Dcal} = +0.728 / +0.586$, both directions clear
of zero) with a clean double crossover ($V_1$ solves the contract and trap cells, $V_2$ solves
key-normalization, all none-baselines floor at $0/40$). Anti-monotonicity reproduces as a verified
collapse on the contract cell: the superset takes \texttt{cache\_put\_ok} from $35/40$ to $0/40$,
$\Delta_T=-0.87$ with an upper bound of $-0.62$ once the budget is spread over the pair's three
contrasts, clearing the margin $\tau=0.30$ fixed for the whole programme. The other two cells do
not: the superset lifts key-normalization from $0/40$ to $40/40$, and on the trap cell it moves
$29/40$ to $26/40$, $\Delta_T=-0.075$, one-sided $90\%$ bounds $-0.3295$ and $+0.1884$. The upper
bound is positive, so this contrast verifies neither the sign of the harm nor the margin. The
dominance control on the same run returns $U_{\Dcal}(W_{1+},W_2)=0.113$, inside the $0.15$
tolerance, with a strict win the other way ($0.65$), so it covers the three-cell battery rather
than a single cell. The relevance trap for this pair was a null, its prompt vocabulary leaning
toward $V_1$ ($\varphi_{\mathrm{lex}}(V_1)=0.39 > \varphi_{\mathrm{lex}}(V_2)=0.25$ on the trap
prompt), so relevance \emph{agreed} with PASS and
the strong mis-rank remains a pair-1 result. The contribution of the second pair is therefore
\emph{generality of the incomparability, dominance and collapse results to a new domain}, not a
second mis-rank.

\paragraph{A character-matched padding control.}
Anti-monotonicity compares $W_1$ against the strictly longer $W_{1+}$, and added input length alone
is known to degrade performance~\citep{contexthurts2025}, so the collapse could in principle be a
token-count effect rather than a signal effect. To isolate this we added a padding arm
$W_{\mathrm{pad}}$: filler text in the same ``team context (private)'' register as $W_2$, placed in
the same position $W_2$ occupies in $W_{1+}$ (padding first, $W_1$ last), character-matched to
$W_{1+}$ within $13$ characters, but carrying no coordinate any verifier checks (office-logistics
content). On Haiku at $n=40$ on the two collapse cells, padding is free while the
equal-length dominated signal is catastrophic: on \texttt{api\_argorder}, $W_1$ $31/40$,
$W_{\mathrm{pad}}$ $40/40$, $W_{1+}$ $0/40$; on \texttt{api\_post\_ok}, $W_1$ $39/40$,
$W_{\mathrm{pad}}$ $40/40$, $W_{1+}$ $0/40$. The padded arm is never verified below $W_1$ alone:
on \texttt{api\_argorder} $\Delta_T=+0.225$ with a two-sided $90\%$ interval of
$[+0.0202,+0.3846]$, clear of zero, and on \texttt{api\_post\_ok} $\Delta_T=+0.025$ with
$[-0.0875,+0.1316]$, consistent with no difference. Against the superset the same-run harm
verification clears on both cells ($\Delta_T=-0.775$, one-sided $90\%$ upper bound $-0.5680$;
and $-0.975$, upper bound $-0.8146$). In the tested configuration the
collapse therefore does not follow from added length alone. The match is by characters, not
subword tokens, and the filler is plain prose while $W_2$ is symbol-dense, so gross length is
constrained but token count and processing difficulty are not. One residual axis is not
isolated by this control: the padding is off-topic for the \texttt{ledger}
module while $W_2$ is on-topic, so ``topical but verifier-irrelevant'' text remains a smaller,
untested middle case.

\paragraph{A routing-instruction ablation: the cure presupposes the diagnosis.}
If the collapse reflects convention confusion, an explicit routing note might prevent it, and if a
one-line prompt fully cured the harm, its practical significance would shrink. We measured this
directly: the arm $W_{1+}^{\mathrm{instr}}$ appends to $W_{1+}$ a single routing sentence stating
which convention serves which task family (``for tasks that call the ledger API use only the API
call contract; the wire-encoding invariant applies only to encode/decode tasks''). On Haiku at
$n=40$ the instruction recovers most, but not all, of the collapse: on
\texttt{api\_argorder}, $0/40 \to 39/40$, and on \texttt{api\_post\_ok}, $0/40 \to 33/40$; both
recoveries over $W_{1+}$ are large, with non-overlapping exact $95\%$ intervals on the two
proportions. Against $W_1$ alone the picture is cell-dependent and much weaker. On
\texttt{api\_argorder} the instructed superset scores $39/40$ against $31/40$,
$\Delta_T=+0.200$, with a one-sided $90\%$ lower bound of $+0.0095$; that separate one-sided
statement clears zero, but the two-sided $90\%$ interval assembled from individual $95\%$ regions
is $[-0.0232,+0.3839]$ and does not. On \texttt{api\_post\_ok} it scores $33/40$ against $39/40$,
$\Delta_T=-0.150$, one-sided bounds $-0.3025$ and $+0.0281$, so neither superiority nor
inferiority to $W_1$ is verified. The record shows that the instruction removes the collapse; it
does not show whether the instructed superset matches $W_1$ alone. We pre-commit to the two readings jointly. First, the harm is substantially mediated by
convention interference that explicit routing knowledge prevents, so pipelines that can attach
per-task routing labels have a cheap mitigation. Second, and decisively for the paper's thesis:
\emph{writing the routing sentence requires already knowing which source is decisive for which
task family}, which is precisely the coordinate structure the partial order formalizes and
the deficiency verification measures; the cure is an injection of selection-time coordinate knowledge
into the prompt, not a scalar score, and no query-independent scalar can supply it
(Theorem~\ref{thm:incomparable}). Formally, $\delta_M$ with the routing note is a
\emph{different, more Blackwell-coherent rule}; the verified falsification of
Theorem~\ref{thm:antimono} concerns the base rule and is unaffected. What the ablation does not
settle is the selection-level question under the instructed rule: the instructed superset sits
below $W_1$ alone on one cell and above it on the other, so on this record keeping the dominated
signal is neither uniformly worse nor uniformly better than dropping it once routing knowledge is
supplied. What the record does support is narrower: without that knowledge, forcing the superset
is verified harmful, and supplying it requires the coordinate structure the partial order
formalizes.

\paragraph{A structured-context ablation: labeled XML segmentation does not mitigate.}
To separate ``the model cannot segment the two conventions'' from ``the model cannot route them
to task families,'' the arm $W_{1+}^{\mathrm{xml}}$ wraps the same two conventions, in the same
order as $W_{1+}$, in labeled XML sections (\texttt{<wire\_encoding\_invariant>},
\texttt{<api\_call\_contract>}) with no routing statement. On Haiku at $n=40$ per
cell, structure alone does not mitigate at all:
$W_{1+}^{\mathrm{xml}}$ scores $0/40$ on both collapse cells, exactly the raw superset's result,
so labelled segmentation without a routing statement is not separated from the superset anywhere
(both $95\%$ intervals $[0.000,0.088]$). The routing note is separated from both on both cells:
$33/40$ on \texttt{api\_post\_ok} ($[0.672,0.927]$) and $39/40$ on \texttt{api\_argorder}
($[0.868,0.999]$). On \texttt{api\_argorder} the routing arm also exceeds this control's own
$W_1$ baseline of $31/40$ ($[0.615,0.892]$), so the ordering is not a graded ladder from
superset to dropping the dominated signal; what the arms separate is segmentation, which changes
nothing, from routing knowledge, which changes almost everything. As in
Section~\ref{sec:disc-mechanism} this localization is an
interpretation of the behavioural contrasts, not a verified claim, and it rests on one model at
$n=40$, with the structure arm and the baselines it is compared against measured in one run.

\subsection{Output-token inflation on the harmful arm}
\label{app:tokens}

Every collapse is accompanied by output-token inflation on the harmful arm. Across the twelve API
collapse cells $W_{1+}$ emits between $+54\%$ and $+321\%$ more output tokens than $W_1$ (Haiku
$+321\%/+55\%$; Sonnet $+283\%/+54\%$; Opus $+229\%/+164\%$; GPT-5.5 $+281\%/+274\%$; DeepSeek
$+93\%/+166\%$; Kimi $+203\%/+249\%$, given as \texttt{api\_post\_ok}/\texttt{api\_argorder}).
One might read this as ``verbose thrashing'' causing the failure, but the relationship is
correlational and uncontrolled: on the \emph{still-passing} encoding cell the same superset arm
ranges from $-73\%$ to $+41\%$ across the same models, with no consistent direction, which
undercuts a clean
``verbosity causes collapse'' account. We therefore treat the token fingerprint as a reproducible
correlate of the harmful arm, not a mechanism.

One qualification governs this whole subsection. The retained completions
(Appendix~\ref{app:audit}) rule out the packaging faults the screens test but do not identify what
replaces them, and no draw in the $480$ replies of the two collapse cells declined the task. That
screen was never run on the three models whose draws were not retained, and elsewhere in the
retained set it is not empty: it matches seven no-context Opus draws.

The claim structure is deliberately mechanism-agnostic: Theorem~\ref{thm:antimono} verifies that
the realized rule is not Blackwell-coherent \emph{whatever} the internal cause, and the behavioral
controls constrain the hypothesis space from outside, the collapse survives reversal of the block
order (order control) and is not reproduced by an off-topic block of equal character length
(padding control), and is largely curable by explicit convention routing
(instruction ablation), a signature consistent with mis-binding rather than capacity exhaustion.
That the one-line routing note recovers most of the collapse ($0/40\to33/40$ and $0/40\to39/40$)
while labeled XML segmentation of the same content recovers none of it ($0/40$ on both cells)
locates the operative variable in convention-to-task routing rather than formatting; this is an
interpretation, not a finding, and every verified claim is independent of it. An activation-level account is out of reach
here, since four of the six models are closed-weight and the phenomenon is cross-vendor; the direct
route is to reproduce the collapse on an open-weight model with the same harness and instrument the
contrasting arms, downstream of rather than prerequisite to the behavioral claim. Distractor
interference in RAG has been localized to a sparse feature subspace and corrected
there~\citep{giannetti2026interference}; ours differs in cause, the added source is each true, and each needed by some task in the battery though not by every task
rather than a distractor, and it is not a knowledge conflict in the sense of
\citet{xu2024knowledgeconflicts}, since nothing in $W_1$ and $W_2$ contradicts.


\section{Reproducibility and protocol}
\label{app:repro}
% ==========================================================================

\begin{sloppypar}
All reported numbers come from real model calls whose outputs are checked by executable verifiers; there
are no modeled or aspirational figures. The complete artifact bundle (the measurement harness, the
executable verifiers, and every per-model run log and result JSON cited below) is available at
\url{https://github.com/abilous-ti/blackwell-llm-context}. The harness (\texttt{harness/measure\_blackwell.py}) is
Python-standard-library only (no third-party dependencies; the Clopper--Pearson endpoints use a stdlib
regularized incomplete beta), is cross-OS, and implements the surrogate $\dhat_{\Dcal}$, the uniform
incomparability verification (\texttt{certify\_incomparable}, \texttt{clopper\_pearson}), the dominance
control (\texttt{certify\_dominance}), the interference verification, the sample-size helpers
(\texttt{required\_n}, \texttt{required\_n\_stark}), and the lexical-relevance scalar
(\texttt{lexical\_relevance}). It includes launchers for the Anthropic Messages API, the
Azure Responses API, and OpenAI-compatible chat completions; the launcher auto-detects API style from the
endpoint, and all API keys are read from the environment (never written to a file).
\end{sloppypar}

\paragraph{Protocol.} The verifier stubs a fake \texttt{ledger} module that accepts \emph{only} the exact
private contract (it rejects wrong positional arg order, a missing \texttt{memo=} keyword, and the wrong
exception type); return code $0$ is PASS. The four verified cells are \texttt{api\_post\_ok},
\texttt{api\_argorder} (\texttt{memo} arrives via a parameter, forcing the keyword-only fact),
\texttt{enc\_amount}, and \texttt{trap\_store\_wire}; the arms are $\{\text{none}, W_1, W_2, W_{1+}\}$,
with $W_{\mathrm{pad}}$ (character-matched neutral filler $\,{+}{+}\,W_1$) added for the padding control.
All six models are queried over HTTP (one request, one turn, the prompt
instructing tool abstention rather than a flag enforcing it; code extracted from the
returned text), and PASS is measured over $n=40$ i.i.d.\ completions per cell at $\eta=0.10$.

\paragraph{Decoding, seeding, and retries.} All runs use the provider's default decoding
configuration: the harness sets no explicit temperature, top-$p$, or seed (the launchers are
invoked without sampling overrides), so the $n$ draws per cell
are independent samples from each provider's default decoder, each a fresh single-turn call with a
$200$-second timeout. This describes every run reported in the paper. Earlier versions of this
record reached the Anthropic models, the four
behavioural controls and the second source pair through the command line; each has since been
re-measured over the API path, and every number reported here comes from those runs, whose logs
carry the \texttt{[HTTP-API]} marker, the raw-failure audit of
Section~\ref{sec:results-audit} included: it reads the completions retained by those API runs
(\texttt{results/retain\_api/}), not the record they replaced.

The following concerns the command-line record that the HTTP runs replaced; no table in this
version is computed from those files, and the one re-measurement still in use is the GPT-5.5 trap
cell described below. Four arm-only re-measurements were originally produced by ad-hoc scripts
that were not kept, so their regime could be asserted but not recovered from a run log. All four
were re-measured with \texttt{harness/diag/rerun\_arm.py}, which calls the same \texttt{run\_one}
the six-model tables are built from and writes a log recording the regime. Three reproduced their
published values closely: the Opus $W_2$/\texttt{trap\_store\_wire} and Haiku
$W_1$/\texttt{enc\_amount} cells returned $0/40$ exactly as before, and the structured-context arm
moved by one draw on one cell. The Opus $W_{1+}$ arm moved further, and deeper: $38\%\to12\%$ on
\texttt{api\_post\_ok} and $15\%\to5\%$ on \texttt{api\_argorder}. Every run cited here has a log
naming its regime;
\texttt{harness/diag/check\_regimes.py} lists them with the evidence for each---an inventory of
the listed runs, not a proof that the list is complete or that each regime is disclosed where its
numbers are used. The between-run
movement on the Opus arm is itself a data point for Section~\ref{sec:limitations}: repeated measurement
of the same cell months apart shifts by more than the nominal interval width. Transport-level failures (empty or zero-token results) are retried up to three
times with quadratic backoff; a draw that still fails is scored as a failure, never as a pass. Where a transport-outage window hit a whole arm or a single cell, we re-measured it cleanly in isolation with the retry harness and report only the clean measurement: the Opus $W_{1+}$ arm; the Opus $W_2$/\texttt{trap\_store\_wire} cell, roughly $18$ of whose $40$ first-run draws were outage-scored (inferred from per-draw cost); and the Haiku $W_1$/\texttt{enc\_amount} cell, whose first run predated the retry wrapper. One cell resisted re-measurement for longer than the others: GPT-5.5 $W_2$/\texttt{trap\_store\_wire} returned HTTP~500 after retries during the original run and no GPT-5.5 deployment was available on the resource at first revision, so for one revision cycle its reported $0/40$ was carried with outage-scored draws in it. A GPT-5.5 deployment was subsequently provisioned and all four GPT-5.5 cells were re-run single-shot at $n=40$ per arm with retention and zero transport failures. The re-run reproduces the published grid exactly in all eight $W_1$/$W_2$ entries, the disputed cell included ($W_2$/\texttt{trap\_store\_wire} $0/40$ clean), so every cell in the coverage family is now a valid binomial sample and the reported $n$ is the number of real draws throughout.

One cell is sourced separately. The base GPT-5.5 run logged an HTTP $500$ on
\texttt{W2}/\texttt{trap\_store\_wire}, so \emph{both} conditions of that task, $W_1$ and $W_2$,
are read from the retained re-measurement with zero transport errors
(\texttt{audit/audit\_gpt55\_trap\_store\_wire\_*}), which returns $40/40$ and $0/40$ from $80$
recorded replies. The two conditions therefore share a measurement window; comparisons involving
GPT-5.5's other tasks remain subject to the between-window stationarity assumption. The reported
percentages are unchanged; what changes is which run they are read from.

\begin{sloppypar}
